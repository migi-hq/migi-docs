# 實機走查清單

**【這是什麼】** 部署後在手機上逐項驗收的操作清單。
**【何時讀】** 每次部署較大改動後；上線前完整走一輪。

> 用手機（優先 LINE 內建瀏覽器）逐項操作，格式：**操作 → 預期結果**。
> 不符的記下「頁面＋現象＋截圖」。全程約 15 分鐘。
>
> **開始前先確認**：Cloudflare Pages → Deployments 顯示綠色 Success
> （build 失敗時會靜默保留舊版，測了也是白測）。

## 0. 進場與註冊
- [ ] 開啟網址 → 進報到頁，版面無破版、無橫向捲動
- [ ] 走完註冊四步 → 成功進入會員主畫面（若已註冊過則直接進入）
- [ ] 歡迎/註冊頁的小熊圖 → 是新版小熊（不是舊的奶嘴熊）

## 1. 外殼（頂欄＋底部 tab）
- [ ] 右上角鈴鐺有紅點 → 點開是「通知」列表（不是直接跳收桌視窗）
- [ ] 通知打開後紅點消失
- [ ] 右上角小頭像 → 開「我的個人檔案」
- [ ] 底部五個 tab 逐一切換 → 無 crash、無白屏

## 2. 通知中心（鈴鐺）
- [ ] 有三筆種子通知：收桌結算／小美想加你為牌咖／雅琪邀你加入牌桌
- [ ] 收桌通知按「查看」→ 開「這桌打完了！」視窗
- [ ] 小美那筆按「接受」→ toast「你和 小美 成為牌咖了！」，通知消失
- [ ] 牌咖頁列表最上方出現小美＋「新加入」pill；按「查看」後 pill 消失
- [ ] 雅琪那筆按「拒絕」→ toast「已拒絕（對方不會收到通知）」，通知消失

## 3. 收桌視窗（讚＋加牌咖）
- [ ] 每位牌咖旁：線條讚圓鈕＋「＋ 加牌咖」
- [ ] 點讚 → 變桃紅實心＋toast；再點取消
- [ ] 按「＋ 加牌咖」→ 變灰「已邀請」；**等 4 秒** → 鈴鐺紅點亮
- [ ] 打開通知 → 「XX 已接受你的牌咖邀請」→ 按查看 → 「你和XX成為牌咖了！」視窗（無「揪TA打一桌」按鈕）

## 4. 牌咖頁
- [ ] 頂部若有待處理邀請 → 顯示粉色橫向提示欄（接受/拒絕可用）
- [ ] 「最近同桌 · 只保留 1 天」區塊：阿凱、婉婷，＋加牌咖 → 已邀請
- [ ] 牌咖列表每行只有「查看」（**不應有**「揪他」按鈕）
- [ ] 「牌咖近況」區無揪按鈕，文案為「開桌時可以邀她一起」
- [ ] 點「查看」→ 他人檔案卡：右上角讚數 pill（線條 icon＋數字）
- [ ] 檔案卡（已是牌咖）→ 無「揪打牌」按鈕，有「邀進牌咖團」＋「開桌時可以邀請」引導語

## 5. 配桌頁（揪牌咖的唯一入口）
- [ ] 「我要配桌」展開設定 → 有「＋ 邀牌咖一起」按鈕
- [ ] 點開 → 邀牌咖抽屜，勾雅琪 → toast「開桌後會自動邀請」；按鈕顯示「已選 1 位」
- [ ] 開始配桌 → 過場後 toast「已邀請 雅琪 加入你的牌桌」
- [ ] 配桌等待卡上有「＋ 邀牌咖加入這桌」→ 點人立即 toast 已邀請
- [ ] 「模擬湊齊」→ 成桌浮窗正常

## 6. 個人檔案＋頭像
- [ ] 個人檔案 Hero 右上：我的讚數 pill
- [ ] 點頭像「更換頭像」→ 七隻段位熊，全部**正圓、大小一致**（大師/雀神灰階鎖定）
- [ ] 選一隻套用 → toast、Hero 立即換、右上角小頭像也換
- [ ] 關掉 App 重開 → 頭像仍是選的那隻（localStorage 有存）

## 7. 成績頁＋錢包頁
- [ ] 成績頁頂部段位卡：金牌熊圖＋「本季 · 金牌熊 II」
- [ ] 錢包頁點數卡右上 pill：「會員等級: 焦糖布丁」

## 8. 埋點驗證（電腦做，跑完 SQL 後）
- [ ] Supabase SQL Editor：`select event, props, created_at from app_events order by created_at desc limit 20;`（service_role 身分）→ 看得到剛才操作的事件流
- [ ] `select last_app_active_at from members where id = '你的測試會員id';` → 有時間
- [ ] `select * from v_app_daily_active;` → 今天有一筆 DAU

## 已知 demo 限制（不算 bug）
- 收桌視窗要從通知點進（真實上線由收桌事件主動彈出）
- 邀請 4 秒自動被接受是 demo 模擬；名單/戰績多為假資料
- LINE 授權是模擬的

## 9. 多帳號互動驗收（B 塊，需右下角測試帳號切換器）

- [ ] 測試01 開 App → 牌咖頁看到測試02（資料庫既有的真實關係）
- [ ] 切到測試03 → 他人檔案送出牌咖邀請給測試01
- [ ] 切到測試01 → 鈴鐺紅點有數字 → 通知中心看到邀請 → 接受
- [ ] 切回測試03 → 通知看到「已接受」、牌咖列表出現測試01
- [ ] 全程 console 沒有 `[social]` 開頭的紅字

## 10. 版本與錯誤機制

- [ ] 設定頁底部顯示版本號（vMMDD-HHmm）
- [ ] SQL 查 `app_events` 最新事件的 props 有 `app_version`，且與設定頁一致
