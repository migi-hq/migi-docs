## 關鍵鐵則（務必遵守）

1. **餘額一律從流水來**：絕不直接 `update wallets set balance=...`,一定透過 RPC（流水 + 快取同步更新）。測試資料造會員也要用 `wallet_topup_tx` 給初始點數,不可直接塞 balance。
2. **改錢只走 RPC / Edge Function**（service_role）：前端永遠不直接寫 wallets/wallet_txns（基石⑱）。
3. **退款用 `reverse_txn_tx`**：不改、不刪原交易,新增反向分錄（基石⑫）。
4. **每筆碰錢操作帶 idempotency_key**：前端產生唯一值,網路重試不重複扣（基石⑧）。
5. **計費金額一律查 pricing_tiers**：調價改資料表,不動程式（資料驅動）。

## 大頭貼（Storage 設定）

會員大頭貼:**照片檔存 Storage、網址存回 Database 的 `members.avatar_url`**(已加欄位)。

### 設定步驟（Dashboard）
1. Dashboard → **Storage** → New bucket → 命名 `avatars`
2. 設為 **Public bucket**(大頭貼可公開讀;若要隱私改 Private + 簽名網址)
3. 上傳照片後得到網址 → 寫進該會員的 `members.avatar_url`

### 流程
```
會員上傳照片 → 存進 avatars bucket（檔名建議用 member_id,如 {member_id}.jpg）
   → 取得 public URL → update members set avatar_url = '...' where id = member_id
```

### 建議
- 檔名用 member_id(好對應、覆蓋舊照不殘留)
- 限制大小(如 < 2MB)、格式(jpg/png/webp),前端壓縮後再上傳
- Database 只存網址(text),絕不把圖片本身塞進資料表
