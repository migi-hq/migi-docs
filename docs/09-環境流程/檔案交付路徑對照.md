# 檔案交付路徑對照與協作規則

> 這是什麼：migi-web 專案檔案結構、交付慣例，以及本輪改動過的檔案清單。
> 什麼時候讀它：收到交付檔要放進 repo 時；或要確認某個功能在哪個檔案時。

---

## 一、專案結構（migi-web）

```
src/
├── styles.css              # 全域樣式 + :root 設計 token
├── App.jsx                 # 主結構、底部 tab 切換
├── DefaultAvatar.jsx       # 預設頭像
├── main.jsx
├── assets/                 # 圖片資產（webp）
├── lib/
│   ├── ui.jsx              # 共用 UI 元件（icon、DateField、Toast、DragSheet）
│   ├── components.jsx      # 共用複合元件
│   ├── helpers.jsx
│   ├── data.jsx            # 假資料
│   ├── tiles.jsx           # 麻將牌相關
│   ├── images.js           # 圖片 registry
│   ├── social.js           # 社交功能 RPC
│   ├── profile.js
│   ├── supabase.js
│   ├── analytics.js
│   ├── ErrorBoundary.jsx
│   └── TestAccountSwitcher.jsx
└── pages/
    ├── wallet.jsx          # tab 1 錢包
    ├── match.jsx           # tab 2 配桌
    ├── stats.jsx           # tab 3 成績
    ├── buddies.jsx         # tab 4 牌咖
    ├── rewards.jsx         # tab 5 獎勵
    ├── profile.jsx         # 個人資料
    └── notifications.jsx   # 通知中心
```

底部 tab：`['錢包', '配桌', '成績', '牌咖', '獎勵']`（純文字，無 icon）

## 二、各頁內容速查

| 檔案 | 內容 |
|---|---|
| `wallet.jsx` | 餘額、儲值、消費明細（分類色麻將圖示） |
| `match.jsx` | 即時配桌、佇列、開局、黑名單 |
| `stats.jsx` | 段位卡、KPI 2×2（胡牌率／放槍率／平均順位／全國排名）、各級距勝率、牌局紀錄（三態）、對戰詳細與牌譜 |
| `buddies.jsx` | 牌咖列表、按讚、搜尋、團隊管理 |
| `rewards.jsx` | 小熊養成、點心櫃、七日簽到、任務、扭蛋 |

## 三、交付慣例

1. **每個交付檔都必須標註 GitHub repo 目標路徑**
2. **不打包壓縮檔**，一律提供個別檔案
3. 驗收方式：上傳新版 zip，請 Claude diff 確認
4. 部署：GitHub → Cloudflare Pages 自動建置

## 五、更新後的驗收檢查點

部署後重點確認：

1. 讚圖示（個人卡右上大拇指）正常顯示
2. 配桌頁佇列分隔線的粉色是否可接受
3. 各頁按鈕、卡片圓角正常
4. 抽屜彈出的陰影正常
5. 報到領獎時 toast 左側跳出小熊餅乾圖
6. 熊卡右上餅乾計數（無底色）在粉色背景上的對比是否足夠
