# 樹莓派計分板安裝步驟

> 2026-11-25 建立。用「樹莓派 5 ＋ 7 吋觸控螢幕」當智慧計分板：開機自動全螢幕打開 `table.migi.tw`，
> 跟平板是同一份程式（配對、教學模式、即時同步、自動更新全部照用，程式一行不用改）。
> ⚠ 這份還沒在實機走過一次。**旋轉螢幕**與**觸控方向**那兩步最可能要調，走完請回來更正這份。

## 0. 要準備的東西

| 東西 | 說明 |
|---|---|
| 樹莓派 5（4GB） | 2GB 也開得動網頁，4GB 比較從容 |
| 官方 27W USB-C 電源（5V 5A） | 🔴 用手機充電器會一直跳低電壓警告、畫面當掉 |
| microSD 卡 32GB 以上 | 選 A2 等級的比較快 |
| 散熱器（官方主動散熱器） | 整晚開著，沒有散熱會降速 |
| 7 吋觸控螢幕 | 官方 Touch Display 2（720×1280），或 Waveshare 7-DSI-TOUCH-A（附外殼版只支援樹莓派 5） |
| USB 鍵盤、滑鼠 | 只有設定時用，設定完拔掉 |
| 一台電腦 | 用來燒系統到 SD 卡 |

iCShop 參考：[Waveshare 7 吋附黑殼](https://www.icshop.com.tw/products/388370100127)、[白殼](https://www.icshop.com.tw/products/388370100130)、
[樹莓派 5 主板分類](https://www.icshop.com.tw/categories/raspberry-pi-boards)（價格以頁面為準）。

## 1. 把系統燒進 SD 卡（在電腦上）

1. 電腦下載安裝 **Raspberry Pi Imager**（官網 raspberrypi.com/software）
2. 選裝置 **Raspberry Pi 5** → 作業系統 **Raspberry Pi OS (64-bit)**（有桌面的那一個）→ 儲存裝置選 SD 卡
3. 按「下一步」時選 **編輯設定**：
   - 主機名稱：`migi-a1`（照桌號取，日後好認）
   - 使用者名稱、密碼：**自己設，記在店裡的帳密本**（之後維護要用）
   - Wi-Fi：店裡的 Wi-Fi 名稱與密碼，國家選 **TW**
   - 時區 **Asia/Taipei**、鍵盤 **us**
4. 寫入，等它跑完、驗證完再拔卡

## 2. 接上螢幕與電源

1. 螢幕的排線接到樹莓派 5 的 **DSI 接頭**（板子上兩個窄的扁平接頭任一個都可以），排線方向照螢幕附的說明
2. 螢幕的供電：用附的杜邦線接樹莓派的 **5V（第 2 腳）** 與 **GND（第 6 腳）**
3. 插 SD 卡、接鍵盤滑鼠，最後才插電源

## 3. 第一次開機

會自動登入桌面。左上角選單 → 附屬應用 → **終端機**，輸入（在樹莓派上，不是你的電腦）：

```bash
sudo apt update && sudo apt full-upgrade -y
```

跑完之後重開機：

```bash
sudo reboot
```

## 4. 螢幕設定

**不要自動關螢幕**：終端機輸入 `sudo raspi-config` → Display Options → Screen Blanking → 選 **No** → Finish。

**轉成橫的**（螢幕本身是直的 720×1280，計分板要橫的）：
左上選單 → 偏好設定 → **Screen Configuration** → 對螢幕（通常叫 `DSI-1`）按右鍵 → Orientation 選 **90** 或 **270** → 套用。

⚠ 轉完**用手指點點看**：點的位置跟畫面對不上，代表觸控沒有跟著轉 —— 這一步要實機試，走到這裡請跟我說是哪一種情況，我再補正確的設定。

## 5. 配對（把這台綁到某一桌）

1. 在樹莓派打開 Chromium（左上角的地球圖示），網址打 `hq.migi.tw`
2. 用 LINE 登入（螢幕上出現 QR，用你的手機 LINE 掃）
3. 進「**智慧計分板**」頁，替這一桌產生配對碼
4. 點下面的「網址（可複製）」框、複製，開一個新分頁貼上、按 Enter
5. 看到計分板畫面（「A1 還沒開桌」之類）就是配好了
6. 回到後台那一頁**登出**，關掉那個分頁 —— 這台機器整晚放在桌上，不要留著後台的登入

## 6. 開機自動全螢幕打開計分板

先查這台的 Chromium 指令叫什麼：

```bash
which chromium chromium-browser
```

印出哪一個就用哪一個（下面以 `chromium` 為例）。建立自動啟動檔：

```bash
mkdir -p ~/.config/labwc && nano ~/.config/labwc/autostart
```

貼上這兩行，按 `Ctrl+O` 存檔、`Enter`、`Ctrl+X` 離開：

```bash
sleep 5
chromium --kiosk --noerrdialogs --disable-infobars --disable-session-crashed-bubble --password-store=basic https://table.migi.tw/ &
```

🔴 **不可以加 `--incognito`（無痕）**：配對資料存在瀏覽器裡，無痕模式每次重開都會清掉，等於每天都要重新配對。

重開機：

```bash
sudo reboot
```

開機後應該直接是全螢幕的計分板。確認沒問題就把鍵盤滑鼠拔掉。

## 7. 平常使用

- **插電就好**：開機約 30～60 秒後自動出現計分板
- **計分板改版**：不用動樹莓派，計分板閒置時會自己重新整理拿到新版
- **要退出全螢幕**（維修時）：接上鍵盤按 `Alt+F4`
- **系統更新**：一兩個月做一次第 3 步的更新指令就好

## 8. 遇到問題

| 狀況 | 先試 |
|---|---|
| 畫面閃爍、右上角出現閃電圖示 | 電源不夠力，換官方 27W 電源 |
| 開機沒有出現計分板 | 接鍵盤，檢查第 6 步的檔案內容與指令名稱（`chromium` 或 `chromium-browser`） |
| 每次開機都要重新配對 | 檢查第 6 步有沒有誤加 `--incognito` |
| 點的位置跟畫面對不上 | 第 4 步的旋轉方向，換 90／270 試試 |
| 螢幕過一陣子變黑 | 第 4 步的 Screen Blanking 要選 No |
