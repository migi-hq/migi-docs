# 🔴 禮券法規對 MIGI「點數」的影響

> 2026-09-05 查證。使用者問「你要不要先讀台灣的法規」—— 對，而查完之後
> 結論比我原本寫的「請律師確認」嚴重得多：**有一項是營運與資金安排，
> 不是條款文字，而且它擋在「開始收儲值」之前。**

---

## 一、現行法規是哪一份

🔴 **舊的分行業版本已被廢止。**

```

現行：商品（服務）禮券定型化契約應記載及不得記載事項
      2020-04-10 會銜訂定 · **2021-01-01 生效**
      （經濟部會同農委會、衛福部、教育部、NCC、交通部、

```

## 二、MIGI 的點數算不算「禮券」

### 法規的定義

> 發行人發行**一定金額**之憑證、磁條卡、晶片卡或**其他類似性質之證券**，
> 消費者以提示等方法向發行人請求交付等值商品或服務。

### 明列的排除只有兩種

| 排除 | MIGI 適用嗎 |
|---|---|
| 發行人**無償**發行之抵用券、折扣券 | ❌ 點數是儲值換來的，**有償** |
| 《電子票證發行管理條例》所稱之電子票證 | ❌ 那是悠遊卡那一類，需特許 |

### 🔴 所以很可能適用

```
客人付 1000 → 帳上多 1000 點 → 可向 MIGI 請求等值商品或服務
```

「其他類似性質之證券」是**概括條款**，記名式儲值餘額落在裡面的機會很高。

⚠ **但這仍是法律解釋問題，不是我能拍板的。**
反面論點存在：記名式儲值帳戶（不流通、不可轉讓）與「禮券」
在性質上可以區別。
🎯 **差別在於：現在有具體的法源與風險可以拿去問，
而不是「不知道，請問律師」。**

## 三、若適用，兩件事會咬

### ✅ ① 不得記載使用期限 —— 我們已經是對的

「不得記載事項」第一點就是**不得記載使用期限**。

✅ `terms.html` 第四條寫的是「**點數無使用期限**」——
當初選這個是因為「保守」，查完才知道**它根本是唯一合法的選項**。
📌 那也是這次查證最直接的收穫：把一個「猜對的保守選擇」
變成「有法源的正確選擇」。

⚠ 同時「不得記載**未使用完之禮券餘額不得消費**」
→ 已補上第四條之四「點數得分次使用，餘額可繼續折抵」。

### 🔴🔴 ② 履約保障機制 —— **這一項擋在收儲值之前**

> 發行人應提供下列任一方式，**自出售日起算至少一年期間**之保障：
> · **金融機構足額保證**
> · **信託專戶**（專款專用）
> · **價金保管服務**
> · **同業（三家以上）連帶擔保**
>
> 變更保障機制時，**保障期間必須接續，不得中斷**。

🔴 **這不是條款文字，是真的要去辦的事**（開銀行帳戶、簽信託契約）。

⚠ **而且它是「應記載事項」** —— 意思是：
```
沒辦好履約保障  ⇒  條款寫不出來
條款寫不出來    ⇒  嚴格說不應該開始賣
```

🎯 **所以它的位置是「第一個真實客人儲值之前」，不是「上線之後再說」。**
📌 今天不咬，因為真實客人是 0 —— 但那個前提隨時會改變。

## 四、其他「應記載事項」對照

| 法定應記載 | MIGI 現況 |
|---|---|
| 發行人**名稱、地址、統一編號、代表人姓名** | 🔴 條款只有名稱與信箱 —— **地址／統編／代表人待補**（等公司登記） |
| 面額 | ✅ 儲值金額 |
| **發售編號及出售日** | ✅ 系統有 `topup_no` 與 `created_at`（`next_doc_no` 自動帶入） |
| 使用方式 | ✅ 條款第四條 |
| **消費申訴（客服）專線** | 🟡 目前只有 `privacy@migi.tw`。法條例示含**電話**，門市電話可補 |
| 履約保障機制 | 🔴 **見上，還沒有** |
| 毀損換發、記名式遺失補發 | 🟡 記名式（綁 LINE）⇒ 帳號取回流程已有，但條款沒對應到這一條 |
| 退還程序與金額 | ✅ 條款第六條 |
| 第三方提供商品時，實收資本額須達 3,000 萬 | ⚪ 不適用（MIGI 自己提供） |

### 🔴 一個要重新檢視的：退款條款

「不得記載事項」有一條是**不得記載較現金消費不利之情形**。

⚠ 我們條款第六條寫「**贈點部分不予退還**」——
🎯 那**應該**站得住腳（贈點是無償取得，不是消費者支付的價金），
但既然法規對「不利待遇」有規範，**這一條要請律師特別看**。

| | 事項 | 誰 | 時機 |
|---|---|---|---|
| ① | 帶著本文件問**律師**：點數是否適用禮券規範 | 你 | 越早越好 |
| ② | 若適用 → 問**會計師／銀行**辦履約保障（信託專戶最常見） | 你 | 🔴 **第一個真實客人儲值之前** |
| ③ | 公司登記完成後補上**地址／統編／代表人**進條款 | 我 | 登記後 |
| ④ | 補**客服電話**（門市電話）進條款 | 我 | 有電話就補 |
| ⑤ | 系統要能**分辨本金與贈點**（待辦 11） | 我 | 條款寫了「贈點不退」而系統算不出來 |
