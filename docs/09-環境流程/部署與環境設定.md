## 二、新專案部署步驟（Cloudflare Pages）

**1. 建 GitHub repo**
- 在 migi-hq organization 下，設 **Private**
- **三個 Add 選項全部不勾**（README / .gitignore / license）——建全空的 repo，否則上傳既有專案會衝突

**2. 上傳檔案（網頁方式）**
- 空 repo 頁面點 **"uploading an existing file"**，或 Add file → Upload files
- 拖曳的是**資料夾裡的內容**（package.json、src/ 等），不是資料夾本身——package.json 必須在 repo 根目錄
- **不要上傳 node_modules**
- 若 `src` 資料夾拖不上去，分兩次：先傳根目錄檔案，再進 src 傳裡面的

**3. Cloudflare Pages**
- Workers & Pages → Create → Pages → Connect to Git → 選 repo

| 設定 | 值 |
|---|---|
| Production branch | `main` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | **留空**（package.json 在根目錄） |

**4. 環境變數（漏了會連不上資料庫）**

| 變數名 | 值 |
|---|---|
| `VITE_SUPABASE_URL` | Supabase → Settings → API → Project URL |
| `VITE_SUPABASE_ANON_KEY` | 同頁的 **anon / public** key |

⚠️ 要用 **anon key**，不是 service_role（那是機密，絕不能放前端）。所有 MIGI 專案共用同一組值。

**5. 綁自訂網域**
專案 → Custom domains → Set up a custom domain → 輸入子網域。因為 migi.tw 已在 Cloudflare，DNS 與 SSL 會自動設好。

**6. 若需要登入功能**
Supabase → Authentication → Add user → 填 email + 密碼 → **勾 Auto Confirm User**（否則要 email 驗證）。
**接著必須把該帳號加進 `staff` 表**（role='hq'），否則 RLS 會擋掉所有讀寫。

## 三、Vite 設定（必要）

```js
// vite.config.js
export default defineConfig({
  plugins: [react()],
  build: {
    target: 'es2015',   // ★ LIFF 舊 WebView 相容，不可移除
  },
})
```

`target: 'es2015'` **永久保留**——移除的話 LINE 內開啟會白畫面（見《踩過的坑》）。

## 四、字型

不要用 Google Fonts（曾造成 403）。CSS 直接以系統字型優先：
```css
font-family: -apple-system, "PingFang TC", "Noto Sans TC", "Microsoft JhengHei", sans-serif;
```
中文顯示幾乎相同，載入更快，也不依賴外部服務。

---

## 五、⛔ 快取處理

**不要建 `public/_headers`。** 曾因此造成 JS 模組回傳 HTML → MIME 錯誤 → 整頁白畫面。

快取問題改用：
- Cloudflare → 網域 → Caching → **Purge Everything**
- 靜態圖片用 query string 版本號：`/bear-lv1.webp?v=2`（換圖時覆蓋同檔名 + 版本號加一）
- Vite 打包的 JS/CSS 自動帶 hash，不用管

## 六、白畫面排查 SOP

1. 開 **乾淨部署網址**（`<hash>.專案.pages.dev`，每次 deploy 專屬、無快取）→ 判斷是伺服器版本問題還是快取問題
2. F12 Console 看紅字
3. Cloudflare → Deployments 確認最新一次是 Success
4. 確認 GitHub 上的檔案真的是最新的、且**放在正確路徑**（拆多檔時最常見的錯是 lib 檔位置放錯）
5. 若乾淨網址正常、但正式網域白畫面 → 純 CDN 快取，Purge Everything 即可
