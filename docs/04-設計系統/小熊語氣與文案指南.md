# 小熊角色語氣與文案指南

> 這是什麼：養成小熊的說話口吻原則、目前使用中的台詞、以及命名文案規則。
> 什麼時候讀它：要新增或修改小熊台詞、養成區文案時。

---

## 一、語氣原則

小熊是**被使用者養大的夥伴**，說話應該：

- **第一人稱、對主人說話**（不是旁白、不是客服語）
- 會撒嬌、會等待、帶點孩子氣
- 短句，口語，可用疑問句拉互動

**反例**：「牌桌準備好了，等你上座。」——太像餐廳帶位、外部視角，不像小熊自己在講話。

---

## 二、目前使用中的 idle 台詞

位於 `src/pages/rewards.jsx` 的 `idle` 陣列，隨機輪播：

```js
const idle = [
  '今天也一起加油吧。',
  '好久不見，今天想打牌嗎？',
  '保持好心情，牌運會更好。',
  '今天想打什麼牌呢。',
  '休息夠了，再戰一局吧。'
]
```

## 三、備用台詞庫（尚未採用）

符合養成夥伴口吻的候選，可視需要替換：

| 台詞 | 特性 |
|---|---|
| 你回來啦，我等好久了。 | 撒嬌等待感，情感最穩 |
| 今天也要一起打牌牌嗎？ | 孩子氣疊字，最萌 |
| 我有乖乖看家喔。 | 討摸討讚 |
| 肚子有點餓了說⋯⋯ | **與餵食機制呼應，能自然導流至點心櫃** |
| 牌運我幫你準備好了！ | 俏皮打包票 |

**推薦優先考慮「肚子有點餓了說⋯⋯」**——它把台詞與養成機制綁在一起，小熊喊餓、使用者就想餵，是能提升互動的文案設計。

### 待辦：語氣統一

目前 idle 陣列中仍有偏旁白口吻的句子（「今天也一起加油吧」「保持好心情，牌運會更好」）。若要全面統一為第一人稱夥伴口吻，需整組重寫。

---

## 四、命名文案規則

### 點心櫃固定用「小熊」

點心櫃（SnackSheet）**不使用小熊自訂名字連動**，一律固定寫「小熊」兩字：

- 標題：小熊的點心櫃
- 副標：收集店裡的點心，餵給**小熊**長大（不同點心成長不同）
- 動作鈕：餵**小熊**
- Toast：餵了**小熊** {品項} · 成長+{N}

`getBearName()` 在此區塊已全數移除。

### 其他區塊仍保留自訂名

養成區主視覺（熊卡下方名字 + 鉛筆改名鈕）仍顯示使用者自訂的小熊名字。

---

## 五、其他成長階段台詞

養成區另有依成長值變化的台詞，例如：

```js
if (grow <= 15) return '有點餓了，補充點能量吧。'
```

這類台詞已符合第一人稱口吻，維持即可。
