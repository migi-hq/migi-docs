# MIGI 咪吉麻將 — 牌面編碼對照表 v1.0

> **這是什麼／何時讀**:42 類台麻牌面的兩碼編碼速查表,含可直接複製的 Python 字典。標註訓練資料、寫辨識程式、或忘記某張牌的代碼時查這份。

> 對應《牌譜成績資料中台技術設計 v0.4》§3。
> **一律兩碼、固定長度**:第 1 碼為數字或字母,第 2 碼為類別 / 區分碼。
> 台麻用語:萬 / 筒 / **條**(不用日麻「索」)。**台麻無紅5**。

---

## 1. 規則速記

| 類別 | 編碼範圍 | 張數 |
|---|---|---|
| 萬 | `1m`–`9m` | 9 種 × 4 = 36 |
| 筒 | `1p`–`9p` | 9 種 × 4 = 36 |
| 條 | `1t`–`9t` | 9 種 × 4 = 36 |
| 風牌 | `E0` `S0` `W0` `N0` | 4 種 × 4 = 16 |
| 三元牌 | `B0` `F0` `C0` | 3 種 × 4 = 12 |
| 花牌 | `H1`–`H8` | 8 種 × 1 = 8 |

- **台16(北部台,有花)= 144 張**
- **南部台(無花)= 136 張**(不含 `H1`–`H8`)

**設計決定:**
- 條用 `t`(條),非日麻的 `s`(索)。
- 字牌以原字母 + `0` 補足兩碼;`0` 無數值意義,僅對齊長度。
- 花牌用 `H`(Hua),避免與三元牌「發 `F0`」的 F 字首混淆。
- **無紅5**:紅五為日麻寶牌機制,台麻不存在。日麻規則集(`ruleset='jp13'`)另於日麻字典定義。

## 3. 程式用字典(Python)

```python
# 碼 → 中文
TILE_NAMES = {
    # 萬
    "1m": "一萬", "2m": "二萬", "3m": "三萬", "4m": "四萬", "5m": "五萬",
    "6m": "六萬", "7m": "七萬", "8m": "八萬", "9m": "九萬",
    # 筒
    "1p": "一筒", "2p": "二筒", "3p": "三筒", "4p": "四筒", "5p": "五筒",
    "6p": "六筒", "7p": "七筒", "8p": "八筒", "9p": "九筒",
    # 條
    "1t": "一條", "2t": "二條", "3t": "三條", "4t": "四條", "5t": "五條",
    "6t": "六條", "7t": "七條", "8t": "八條", "9t": "九條",
    # 風牌
    "E0": "東", "S0": "南", "W0": "西", "N0": "北",
    # 三元牌
    "B0": "白", "F0": "發", "C0": "中",
    # 花牌
    "H1": "春", "H2": "夏", "H3": "秋", "H4": "冬",
    "H5": "梅", "H6": "蘭", "H7": "竹", "H8": "菊",
}

# 中文 → 碼(反查)
TILE_CODES = {v: k for k, v in TILE_NAMES.items()}

# 牌組組成(每種牌幾張)
def build_wall(with_flowers=True):
    """回傳完整牌組。台16(有花)144 張;南部台(無花)136 張。"""
    wall = []
    for suit in ("m", "p", "t"):
        for n in range(1, 10):
            wall += [f"{n}{suit}"] * 4
    for honor in ("E0", "S0", "W0", "N0", "B0", "F0", "C0"):
        wall += [honor] * 4
    if with_flowers:
        wall += [f"H{n}" for n in range(1, 9)]   # 花牌各 1 張
    return wall

# 分類判斷
def is_suit(tile):    return tile[1] in ("m", "p", "t")   # 數牌
def is_wind(tile):    return tile in ("E0", "S0", "W0", "N0")
def is_dragon(tile):  return tile in ("B0", "F0", "C0")
def is_honor(tile):   return is_wind(tile) or is_dragon(tile)
def is_flower(tile):  return tile[0] == "H"
```

**驗算**:`len(build_wall(True))` = 144;`len(build_wall(False))` = 136。

## 4. 排序建議(顯示 / 理牌用)

牌譜顯示與理牌時的建議排序:**萬 → 筒 → 條 → 風(東南西北)→ 三元(白發中)→ 花**

```python
SUIT_ORDER = {"m": 0, "p": 1, "t": 2}
HONOR_ORDER = {"E0": 0, "S0": 1, "W0": 2, "N0": 3, "B0": 4, "F0": 5, "C0": 6}

def sort_key(tile):
    if is_flower(tile):
        return (4, int(tile[1]))
    if is_honor(tile):
        return (3, HONOR_ORDER[tile])
    return (SUIT_ORDER[tile[1]], int(tile[0]))

# 用法:sorted(hand, key=sort_key)
```

## 5. 日麻擴充預留(現行停用)

引進日麻規則集(`ruleset='jp13'`)時:

- **紅5**:另定義 `0m` `0p` `0s`(維持兩碼制)。台麻牌組不受影響、不含此三碼。
- **索 ↔ 條**:同一實體牌,日麻稱「索」、台麻稱「條」。統一以 `1t`–`9t` 儲存,顯示層依 ruleset 切換稱呼即可,不需兩套碼。
- **無花**:日麻 136 張不含 `H1`–`H8`。
