# 台麻牌辨識 — Windows 零基礎操作手冊 v1.0

> **這是什麼／何時讀**:給零基礎 Windows 使用者的逐步操作手冊,從安裝 Python 到訓練出第一個台麻辨識模型。真的要動手裝環境、標註、訓練時照著做。

> 對象:沒碰過 Python、用 Windows、手邊有一副麻將牌。
> 目標:從什麼都沒有,到「電腦看得懂你那副麻將牌」。
> 全程複製貼上指令即可,遇到卡關的地方我在每步後面標了「可能出錯」。

---

## 開始前:先看懂這件事

你要弄的其實是**兩樣不同的東西**,別搞混:

| 東西 | 是什麼 | 怎麼來 |
|---|---|---|
| **YOLO** | 會辨識的「引擎」 | 一行指令安裝,5 分鐘 |
| **台麻牌模型** | 教引擎認得你那副牌的「檔案」 | **要你自己訓練**,這才是主要工作 |

網路上找得到的麻將模型**幾乎都是日麻牌組**(有紅5、沒花牌),認不出台麻的花牌。所以最後一定要自己訓練。

**整體工時預估**:安裝環境半天;拍照+標註 1~2 天(最花時間);訓練 30 分鐘~數小時。

---

## 第一階段:裝好環境(約半天)

### 步驟 1:安裝 Python

1. 打開瀏覽器,去 **python.org**,點 Downloads
2. 下載 **Python 3.12**(不要下載最新的 3.13,套件相容性有時跟不上)
3. 執行安裝檔,**⚠ 最重要的一步**:安裝畫面最下方有個勾選框
   ```
   ☑ Add python.exe to PATH
   ```
   **一定要打勾**,不打勾後面所有指令都會失敗。
4. 點 "Install Now",等它跑完

**可能出錯**:忘記勾 PATH → 後面打 `python` 會說「不是內部或外部命令」。解法:重跑安裝檔,選 Modify,把 PATH 勾起來。

### 步驟 2:確認裝好了

按鍵盤 `Win + R`,輸入 `cmd`,按 Enter,會跳出一個黑色視窗(這叫「命令提示字元」,以下簡稱終端機)。

輸入這行,按 Enter:

```
python --version
```

**看到 `Python 3.12.x` 就成功了。**

**可能出錯**:跳出 Microsoft Store → 代表 PATH 沒設好,回步驟 1 重來。

### 步驟 3:安裝 YOLO

在同一個終端機視窗,貼上:

```
pip install ultralytics
```

按 Enter,等它跑(會下載一堆東西,幾分鐘)。看到 `Successfully installed...` 就好了。

**可能出錯**:網路慢會中斷 → 重跑一次同樣指令即可,它會接續。

### 步驟 4:測試 YOLO 活著

```
yolo predict model=yolo11n.pt source=https://ultralytics.com/images/bus.jpg
```

它會自動下載一個「通用模型」,然後辨識一張公車照片,結果存在 `runs\detect\predict` 資料夾裡。

**打開那張圖看看**——公車、行人被框起來了,代表 YOLO 正常運作。

> ⚠ 注意:這個通用模型**不認得麻將牌**。它只認得人、車、狗那些。認麻將牌要靠你自己訓練的模型。

## 第二階段:拍訓練照片(最花時間,但最關鍵)

### 為什麼一定要自己拍

- 網路上的資料集是**日麻牌**,沒有花牌(春夏秋冬梅蘭竹菊)
- 麻將牌**每個廠牌長得不一樣**,同一張「五筒」設計差很多
- **你是連鎖店,牌是你統一採購的** → 用你自己的牌訓練,辨識率會比通用模型高很多。這是你的優勢。

### 拍多少張?

參考康乃爾大學一組學生的實測:**約 150 張原始照片**,再用「資料增強」(自動旋轉、調亮度)擴增到約 1000 張,YOLO 訓練後達到接近 100% 準確率。

所以目標:**150~300 張原圖**。不用幾千張。

### 怎麼拍(重點)

**核心原則:拍成「你未來實際使用時會看到的樣子」。**

你的系統有兩種鏡頭,拍照時要涵蓋兩種場景:

**A. 側面鏡頭場景(優先,最好拍)**
- 把 16 張牌像起手牌那樣**攤平、正面朝上、排成一排**
- 從玩家的視角(牌面朝鏡頭)拍
- 這是最容易辨識的情境,先把這種拍好

**B. 俯視鏡頭場景(較難)**
- 牌散落在桌面中央(像海底混堆)
- 從正上方拍
- 有些牌會被壓住、有些會斜著

**每種場景都要變化這些條件:**

| 變化項目 | 怎麼做 |
|---|---|
| 光線 | 開燈、關燈、只開桌燈、有陰影、有反光 |
| 角度 | 正對、左偏、右偏、高一點、低一點 |
| 距離 | 近拍、遠拍 |
| 背景 | 不同顏色的桌布 |
| 遮擋 | 有手擋住一部分、牌壓著牌 |

**⚠ 花牌一定要拍夠**:`H1`–`H8`(春夏秋冬梅蘭竹菊)公開資料集完全沒有,而且每張只有一張,容易拍太少。**花牌要特別多拍幾組。**

**用什麼拍**:手機就好。但**建議用你未來實際要裝的那支鏡頭拍**,因為不同鏡頭的畫質、色偏會影響辨識。如果還沒買鏡頭,先用手機拍,之後鏡頭買了再補拍一輪。

## 第三階段:標註照片(枯燥但必要)

「標註」= 在每張照片上,把每張牌框起來,告訴電腦「這個框裡是 5p(五筒)」。

### 用 Roboflow(免費、瀏覽器就能用,不用裝東西)

1. 去 **roboflow.com**,註冊免費帳號
2. 建一個新專案,類型選 **Object Detection**
3. 上傳你拍的照片
4. 開始標註:用滑鼠框住每一張牌,選類別

### 類別怎麼設(用你的兩碼編碼)

照《牌面編碼對照表 v1.0》設 **42 個類別**:

```
1m 2m 3m 4m 5m 6m 7m 8m 9m        (萬,9類)
1p 2p 3p 4p 5p 6p 7p 8p 9p        (筒,9類)
1t 2t 3t 4t 5t 6t 7t 8t 9t        (條,9類)
E0 S0 W0 N0                        (風,4類)
B0 F0 C0                           (白發中,3類)
H1 H2 H3 H4 H5 H6 H7 H8            (花,8類)
```

**⚠ 不要設 `0m` `0p` `0s`(紅5)——那是日麻的,台麻沒有。**

也可以多設一類 `back`(牌背),讓模型認得「這張是背面、看不到內容」——對俯視鏡頭有用。

### 這步的真話

**這是整個專案最無聊、最花時間的部分。** 150 張照片、每張 16 張牌,就是 2400 次框選。有心理準備。

**省力技巧**:標完前 50 張後,先訓練一個粗糙模型,用它去「自動標註」剩下的照片,你只要修正它標錯的地方。Roboflow 有這個功能(Label Assist)。

### 標完後

Roboflow 裡點 **Generate**,設定資料增強(Augmentation):
- Rotation(旋轉)±15°
- Brightness(亮度)±25%
- Blur(模糊)輕微

這會把你 150 張自動擴增到 1000 張左右。

然後 **Export**,格式選 **YOLOv11**,它會給你一個下載連結或一段程式碼。

## 第四階段:訓練模型

### 先確認你的電腦有沒有 NVIDIA 顯卡

終端機輸入:

```
nvidia-smi
```

- **有跳出一個表格** → 你有 NVIDIA 顯卡,訓練會很快(30 分鐘內)
- **說「不是內部或外部命令」** → 沒有獨立顯卡,純 CPU 訓練會**很慢**(可能好幾小時)

### 路線 A:有 NVIDIA 顯卡 → 在自己電腦訓練

先裝 GPU 版的 PyTorch(不裝的話 YOLO 只會用 CPU):

```
pip uninstall torch torchvision -y
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

然後把 Roboflow 下載的資料集解壓到,例如 `C:\mahjong\dataset`,執行:

```
yolo train model=yolo11n.pt data=C:\mahjong\dataset\data.yaml epochs=100 imgsz=640
```

訓練完,你的模型檔在 `runs\detect\train\weights\best.pt` —— **這就是你的台麻牌模型。**

### 路線 B:沒有顯卡 → 用 Google Colab(免費借 GPU)

1. 去 **colab.research.google.com**(用 Google 帳號登入)
2. 新增筆記本
3. 上方選單 → 執行階段 → 變更執行階段類型 → 硬體加速器選 **T4 GPU**
4. 在格子裡貼上(依序執行):

```python
!pip install ultralytics roboflow
```

```python
from roboflow import Roboflow
rf = Roboflow(api_key="你的_ROBOFLOW_API_KEY")
project = rf.workspace("你的workspace").project("你的專案名")
dataset = project.version(1).download("yolov11")
```
(上面這段 Roboflow 匯出時會直接給你,複製貼上就好)

```python
!yolo train model=yolo11n.pt data={dataset.location}/data.yaml epochs=100 imgsz=640
```

訓練完在左邊檔案區找到 `runs/detect/train/weights/best.pt`,下載到你電腦。

**Colab 免費版限制**:連續使用有時數上限、閒置會斷線。訓練 100 epochs 通常來得及。

## 第五階段:用你的模型辨識麻將牌

把 `best.pt` 放到方便的地方,例如 `C:\mahjong\best.pt`。

**辨識一張照片:**

```
yolo predict model=C:\mahjong\best.pt source=C:\mahjong\test.jpg
```

**辨識一支影片**(這就是「錄影事後跑」!):

```
yolo predict model=C:\mahjong\best.pt source=C:\mahjong\牌局.mp4
```

結果存在 `runs\detect\predict`,你會看到每張牌被框起來、標上 `5p`、`H3` 這些代碼。

---

## 接下來:接上你的 hand_tracker

到這裡,YOLO 會告訴你「這張照片裡有哪些牌」。

而你的 `hand_tracker.py` 需要的輸入,正好就是「一串牌的代碼」。所以下一步是寫一小段程式,把 YOLO 的輸出轉成 hand_tracker 吃得下的格式:

```python
from ultralytics import YOLO
from hand_tracker import HandTracker

model = YOLO(r"C:\mahjong\best.pt")
tracker = HandTracker("東家")

# 對每一張快照
results = model(r"C:\mahjong\snapshot_001.jpg")
tiles = [model.names[int(box.cls)] for box in results[0].boxes]   # → ["1m","5p",...]

event = tracker.feed(tiles)   # → 算出摸了什麼、打了什麼
print(event)
```

**這段接上去,整條鏈路就通了**:鏡頭 → YOLO 辨識 → hand_tracker 算摸打 → JSONL 事件流 → Supabase。

## 誠實的提醒

1. **你會卡關**,而且大概會卡在環境安裝(PATH、套件版本衝突)。這是每個第一次弄的人都會遇到的,不是你的問題。卡住把錯誤訊息貼給我。

2. **辨識率不會一次到位**。第一版模型可能認錯很多,尤其是:
   - 花牌(圖案複雜、每張只有一張、訓練資料少)
   - 一條 vs 一筒(有些設計很像)
   - 牌被手擋住、斜放、反光

   解法永遠是**補拍那些認錯的情境的照片、重新訓練**。這會來回幾輪。

3. **側面鏡頭(攤平的牌)會比俯視(混堆、動態)準很多**。俯視抓「牌飛出去落地那一瞬間」是整套系統最難的部分,很可能是最後的準確率瓶頸。**先把側面做出來,別一開始就挑戰俯視。**

4. **先錄影再說**。在你裝任何東西之前,拿手機去錄幾場實際牌局。**沒有真實畫面,裝好 YOLO 也沒東西可測。**

## 建議的實際順序

1. ☐ 拿手機錄 2~3 場實際牌局(側面視角優先)
2. ☐ 裝 Python + YOLO(第一階段)
3. ☐ 拍 150 張牌照(第二階段)
4. ☐ Roboflow 標註 + 增強(第三階段)
5. ☐ 訓練模型(第四階段)
6. ☐ 拿錄好的影片測試辨識(第五階段)
7. ☐ 接上 hand_tracker,跑出第一份真實牌譜

**第 1 步今天就能做,不用裝任何東西。**
