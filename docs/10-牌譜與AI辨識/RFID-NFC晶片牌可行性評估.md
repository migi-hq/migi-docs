# RFID / NFC 晶片牌可行性評估

> **這是什麼／何時讀**:評估在麻將牌裡內建 RFID/NFC 晶片的技術可行性、法規未知數與品牌風險。有人提「要不要上感應牌」時,先讀這份再決定要不要重啟討論。**結論是現階段不做**,但技術路徑本身可行,留給未來需要時參考。

## 一句話結論

**技術上可行,但不是「你自己弄」的專案;現階段建議不碰,原因不只成本,更包含品牌風險。**

---

## 一、技術層

### NFC 不適合,要用 RFID

NFC 是超短距離(幾公分)、一次讀一張的技術(手機刷卡那種)。要「一次讀出整副 16 張手牌」,NFC 做不到。

**UHF RFID** 讀取距離較遠、能同時讀取大量標籤(防碰撞機制),是賭場/庫存管理常用的技術等級。市面確有電動麻將桌宣稱配備 RFID 識別技術——但此類資訊來自行銷內容,可信度需另向實體廠商查證,不可盡信。

### 核心工程難點:RFID 給身分,不給位置

RFID 讀取器只會說「五筒 #3 在附近」,不會說它在誰手上、在海底、還是在牌牆裡。但牌譜要的正是位置。所以核心工程是**天線分區**:每個座位下方一組天線、海底一組、吃碰槓區一組,靠讀取範圍 + 屏蔽讓「哪組天線讀到」等於「它在哪一區」。

這也是為什麼 **UHF 反而不理想**——讀取距離遠是優點也是缺點,牌在隔壁座位也讀得到,分區會互相串擾。**HF(13.56MHz)這種短距離技術反而更適合**,短距離天生就是分區隔離。

### 對台麻有利的一點:牌尺

台麻手牌立在牌尺上、放在桌面,不是拿在手上。只要牌尺下方埋一組天線,整副手牌隨時讀得到、每秒都準——**這剛好解掉鏡頭方案的手搓死角**(RFID 不看牌面,牌背朝哪都無所謂)。

而且 `hand_tracker` 的前後比對邏輯完全不用丟——只是把「YOLO 辨識出的手牌」換成「RFID 讀出的手牌」,**辨識層換掉,邏輯層原封不動**。

### 其他硬工程問題

1. **磁鐵衝突(最麻煩)**:電動麻將桌靠磁力把牌吸進上牌口,牌裡本來就有磁鐵。金屬會讓 RFID 天線失諧,兩者塞進同一張 26mm 的牌是實打實的射頻設計難題。要嘛避開位置、要嘛用抗金屬標籤、要嘛放棄自動桌。
2. **同款四張要有獨立 ID**:四張五筒必須分得出來,否則牌牆追蹤、摸牌來源都算不準——需逐張寫入、逐張登錄。
3. **牌牆要不要讀**:要拿到「牌山序」,牌疊在牆上兩層,要讀出**位置順序**而不只是「在牆區」,比讀手牌難一個量級。
4. **耐用度**:牌會被摔、被搓、被洗牌機攪,標籤要撐幾年。
5. **要訂製牌**:市面沒有現成的台麻 RFID 牌(尤其花牌),需找廠商開模訂製。對連鎖店統一採購來說不是壞事,但要算起訂量與開模費。

---

## 二、法規層(未查證,不可當真)

台灣的無線射頻器材原則上要經過 NCC 相關型式認證。但「自己在牌裡埋標籤、自己裝讀取器」算不算、要走哪套程序,**未經查證,不能給出答案**。這種事要問 NCC 或本地 RFID 廠商,不是能憑印象判斷的。

---

## 三、品牌與信任風險(真正的決定性因素)

在台灣/中國的麻將圈,「牌桌裡有感應器/晶片」幾乎等同於作弊聯想:
- 台灣媒體曾報導電動麻將桌加裝作弊器、可設定拿到什麼牌
- 中國大陸曾破獲詐賭集團在自動麻將桌出牌口裝隱藏鏡頭、遠端指導出牌
- 麻將機維修相關討論中,牌咖普遍懷疑機台是否作弊

**MIGI 是「女性友善、健康麻將」品牌,文件明文賭博紅線。而在牌裡埋晶片讓系統即時知道每張牌在誰手上,從客人角度看,跟作弊機的差別只有「你說你不會用」而已。**

這是鏡頭方案沒有的問題。鏡頭拍得到的是公開資訊 + 每人自己的手牌(各看各的);晶片牌是**桌子本身知道一切**,信任結構完全不同。鏡頭方案雖有死角(手搓、留手),但「看得到什麼」對客人可解釋、可驗證——鏡頭在哪、拍到什麼,一眼就懂。

---

## 四、跟鏡頭方案的對照

| | 鏡頭方案 | RFID 方案 |
|---|---|---|
| 本質 | 軟體問題 | 硬體 + 射頻工程問題 |
| 你能自己做嗎 | 能(目前正在做的) | 基本上不行,須找廠商合作 |
| 準確率 | 有死角,靠三方對帳補 | 天生接近 100% |
| 起手成本 | 幾萬 | 開模 + 天線 + 讀取器,量級高很多 |
| 迭代速度 | 改程式,當天見效 | 改硬體,幾週幾個月 |
| 品牌觀感 | 可解釋、各看各的 | 容易被聯想為作弊/監控 |

---

## 五、結論與建議

**不碰,不是因為做不到,是因為它跟品牌定位正面衝突,且投入結構完全不同(自己能做 vs 得靠廠商)。**

若未來要做**賽事桌/直播桌**(選手事前同意、全程公開、有裁判),晶片牌或感應桌是合理選項——但**一般營業桌不建議**。

**建議路線**:先把鏡頭方案做到極限,拿到真實準確率數字,再判斷貴的方案值不值得。鏡頭階段的投入(`hand_tracker`、資料結構、Supabase、viewer、統計維度)全部不會白費——未來真要換 RFID,換的只是最前面的辨識層那一小塊。反過來做(先上 RFID 再退回鏡頭)會很痛。
