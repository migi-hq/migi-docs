# 可跑 YOLO 的硬體選項比較

> **這是什麼／何時讀**:除了樹莓派之外,還有哪些設備能跑辨識模型的完整比較,含各階段建議。要決定「現在用什麼機器測試」或「裝上牌桌要買什麼」時讀這份。

## 核心原則

**樹莓派不是「影像辨識的方法」,它只是一台跑辨識程式的小電腦。** 真正做辨識的是模型(YOLO)。

**YOLO 對硬體不挑,幾乎什麼都能跑,差別只在「跑多快」。** 同一模型在強機一秒跑三百張,在樹莓派上可能一秒跑三張。所以問題從來不是「能不能跑」,而是「需要多快」——而側面鏡頭每 1~2 秒拍一張,根本不需要快;只有俯視鏡頭(要抓牌飛出去的瞬間)才真的需要速度。

---

## 選項一覽

### 一、你現在就該用的:自己的電腦

原型階段的正解。任何筆電/桌機都能跑 YOLO。有獨立顯卡(NVIDIA)快很多,沒有的話純 CPU 也跑得動、只是慢——但配合「錄影事後跑」的原型策略,慢一點完全無所謂。**零採購,今天就能開始。**

### 二、專門的 AI 邊緣運算裝置(要裝上牌桌時才考慮)

| 裝置 | 特性 |
|---|---|
| **NVIDIA Jetson 系列**(Orin Nano / Orin NX / AGX Orin) | 跑 YOLO 的正統選擇,內建 GPU,生態最成熟、教學最多。較貴、較耗電。 |
| **樹莓派 + Hailo 加速棒** | 便宜、省電,靠加速棒補算力(即目前定案的方案二)。 |
| **Google Coral(Edge TPU)** | 很省電很小,但只吃特定格式模型(需轉 TFLite 量化版),YOLO 轉過去麻煩,新版 YOLO 支援不佳,**不建議**。 |
| **Intel 神經運算棒 / OpenVINO** | 搭 x86 迷你 PC 用的加速方案。 |

### 三、一般電腦類(當中控主機)

- **x86 迷你 PC**(Intel N100 那類,三四千元):好除錯、環境熟悉。純 CPU 偏慢,但接側面鏡頭(1~2 秒一張)夠用。
- **加一張顯卡的桌機**:店裡若本來就有電腦,插張 NVIDIA 顯卡就是很強的辨識機。

### 四、雲端(不買硬體)

錄影上傳,租雲端 GPU 跑辨識,跑完結果存進 Supabase。
- 好處:不用買任何東西,要多強有多強。
- 壞處:要上傳影片(檔案大)、按時間計費、有延遲。
- 適合:「錄影事後跑」的驗證階段,尤其要一次跑很多場影片時。

### 五、手邊可能有的

- **手機**(iPhone / Android):現代手機 AI 晶片其實很強,有現成 App 能跑 YOLO,當側面鏡頭是零成本方案。
- **Mac(M 系列晶片)**:M1/M2/M3 跑 YOLO 意外地順。

---

## 按階段建議

| 階段 | 用什麼 |
|---|---|
| **現在(錄影驗證)** | 你自己的電腦,或雲端 GPU。**不用買東西。** |
| 裝上牌桌(即時) | Pi 5 + Hailo(便宜,現行定案方案二)或 Jetson Orin(強,實測算力不足時的升級路線) |
| 店裡已有電腦 | 插張 NVIDIA 顯卡就好 |

## 真正的瓶頸不是硬體

不管選哪台機器,都繞不開同一件事:**你需要一個認得台麻牌的模型**,而這需要標註好的台麻牌照片來訓練。這件事沒有捷徑,而且是整個專案最耗時的部分,遠比選硬體耗時。設備清單再長,都不是現在的瓶頸——現在的瓶頸是有沒有現成的台麻牌辨識資料集可用(結論:公開資料集幾乎全是日麻牌組,見《台麻牌辨識 Windows 操作手冊》)。
