# MIGI 牌桌區裝潢預留需求清單

> **這是什麼／何時讀**:給室內設計師/統包的裝潢預留規格,不需懂鏡頭系統,照著預留即可。要裝修牌桌區、或跟工班溝通鏡頭/走線/電源預留時用這份。同內容也有排版過的 PDF 版可直接列印給設計師。

**給設計師的一句話**:每張牌桌要裝 5 支小型攝影機(記錄牌局用)。攝影機由我方提供,你只需在裝潢階段預留「藏它的位置、走線、電源」,不需要懂攝影機系統。

## 一、每張牌桌的攝影機位置(共 5 支)

- **4 支側面(一人一支)**:每位客人**頭頂偏後方**一支、往下拍他自己面前立著的手牌——
  鏡頭看到的角度要跟客人自己看牌的角度接近，因為牌面是朝著客人的。四支各顧一家、不重疊、不擋動線。
- **1 支俯視**:牌桌**正上方**、垂直朝下,拍桌面中央。

每支側面鏡頭只拍「自己這一家」的牌,拍不到別家(別家的牌面朝各自的方向)——天然做到「一人一鏡、各看各的」。

🆕 **可以分階段裝**：第一階段只裝**俯視 1 支**（拍得到打出的牌、吃碰槓），側面 4 支以後再加。
但**側面的吊點與走線要在裝潢時一次預留**，事後補很難看（見《AI 硬體部署與產品分級》§8）。

## 二、側面攝影機的載體:客人後上方的吊點

- 每位客人座位的**後上方**預留一個固定點，讓鏡頭能伸到客人頭頂偏後、朝下拍。可選的做法：
  - 天花板吊點（跟俯視鏡頭、吊燈同一個系統）
  - 座位後方的立柱或牆面支架
  - 桌區上方的軌道或燈架
- 高度與俯角**一定要先實拍再固定**（見第七點）：要拍得到立起來的牌面，又不能被客人的頭或身體擋住。
- ⚠ **不能藏在桌角或置物櫃裡**：那些位置都在客人前方或側前方，拍到的是牌背。
- 四角置物櫃仍然可以做（給客人放包包、手機），也可以**藏主機、走線、平板的電源**，只是不放側面鏡頭。
  現成方案：IKEA BESTÅ 或 VIHALS（MDF 材質好開孔、官方即設計來藏線藏 3C），或依尺寸訂製木工。

## 三、俯視攝影機的吊點

- 牌桌正上方天花板預留一個**吊掛點 + 出線口**。
- 建議**與牌桌上方吊燈整合**(燈具與鏡頭同一組吊件),避免天花板多一根突兀的桿子。
- 🆕 **燈要用柔光、面光源**：麻將牌面會反光，正上方是點光源的話，鏡頭會拍到整片反白。燈具選型要跟鏡頭一起看。

## 四、走線(重點,事後補很醜)

- 每支攝影機要一條線**回到中央主機**。
- 4 支側面的線從**後上方吊點沿天花板或牆面**走（不要拉過客人座位）,桌面不露線。
- 俯視的線走**天花板 → 牆面 → 中央主機**。
- 全部預埋**線槽/線管**,牆面/地面不露線。

## 五、電源與網路

| 項目 | 需求 |
|---|---|
| 插座（攝影機） | 攝影機走網路線供電（PoE）就不需要插座；只有**中央主機與網路交換器**要獨立插座。原型階段用 USB 攝影機時，才需要在 4 個側面吊點 ＋ 1 個俯視吊點附近各留插座。 |
| **插座（記分平板）** | 🆕 **每桌再多 4 個**,給四台記分平板長期插電。位置在四位客人手邊(見下)。 |
| 網路 | 🆕 **每個攝影機點位預留一條網路線（CAT6）** —— 正式門市的攝影機用同一條線供電又傳影像（PoE），就不必再拉插座；Wi-Fi 只給平板用（《AI 硬體部署與產品分級》§3）。 |

### 🆕 5.1 記分平板的電源（2026-09-20 追加）

每張牌桌會放 **4 台平板**(客人自己記分用),**固定放在那一桌不移動**。

```
每桌插座總數  = 4（平板）＋ 攝影機用的（PoE 正式版 0 個；USB 原型版 5 個 ＋ 主機 1 個）
```
🎯 **平板固定不動 ⇒ 一直插電 ⇒ 不用管電池、不用每天收回充電。**
但那要**每個座位手邊有插座**,而插座是裝潢階段的事。

⏳ **還要決定平板放哪裡**(這一格會影響插座位置,請設計師一起想):
```
桌角        會佔到打牌空間
旁邊小几     跟飲料共用,可能被打翻
桌邊臂架     不佔桌面,但要在櫃體上鎖固定座
```

### 🔴 5.2 Wi-Fi 要按實際裝置數算,不能只寫「訊號要夠強」

```
14 桌 × 4 台平板 = 56 個裝置同時連線，再加上客人自己的手機（手機計分板）
```
🆕 攝影機改走網路線（PoE）之後不佔 Wi-Fi；但客人可以用自己的手機當計分板，**實際連線數會比平板數更多**。
🔴 **家用路由器撐不住** —— 一般家用機的實際同時連線上限約 20~30 台,
超過會開始掉線,而**症狀是「偶爾連不上」不是「完全不能用」**,最難查。

→ 需要**商用 AP**(多台佈點、支援高密度連線)。
⚠ 這是網路設備商的規格,不是統包的工作,但**佈線與 AP 吊點要在裝潢階段預留**。

## 六、中央主機藏放位置

- 原型階段每桌一台小主機(約便當盒大小)；正式門市改成**多桌共用一台主機 ＋ 網路交換器**，放在機櫃或後場（《AI 硬體部署與產品分級》§3、§4）。
- 需一個**通風、藏得住、接得到電與網路**的位置——原型那台可藏在其中一個置物櫃下層。

## 七、施工順序的關鍵提醒

1. 吊點固定前,**先用臨時腳架把鏡頭擺到客人頭頂偏後的位置實拍**,確認角度能清楚拍到立起來的手牌，而且不會被頭擋住。
2. 角度確認後,才把吊點、走線固定進裝潢。
3. **先做一桌當樣板,驗證 OK 再複製到其他桌。**

## 八、品牌注意事項(女性友善定位)

- 攝影機要**藏得美觀、融入家具**,不要像監視器。
- 但**不隱瞞**:明確告知客人「這是記錄牌譜用、各人只拍自己的牌」。沙龍式的精緻感與「被監視感」只差在**透明度**。
- 🆕 **手牌畫面不提供任何即時觀看**（包括店員）——能即時看到別人底牌的系統等於作弊工具。店內告示可以直接寫出這一句，客人會更安心（《AI 硬體部署與產品分級》§9）。
