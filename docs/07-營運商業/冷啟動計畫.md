# MIGI 麻將連鎖 — 冷啟動計畫 v1.0(開店前 90 天 → 開店後 90 天)

> 死結:麻將店冷啟動是雞生蛋問題——沒人→湊不成桌→白跑失望→口碑「那家都沒人」→更沒人。
> **唯一目標:從第一天起,讓每個走進來的人都有牌打。**
> 本計畫上位依據:《戰略備忘》隱憂三(99% 誘因 = 有牌打,成桌率 = 核心產品)。

---

## 打法一:招「團」,不招「人」(種子策略核心)

**觀念:散客 = 1/4 桌(要靠湊,湊不出就流失);牌咖團 = 一整桌(自己成局,零風險)。招募單位是「團」。**

| 來源 | 做法 | 備註 |
|---|---|---|
| 現成牌咖團 | 固定在家打的閨蜜團/社區媽媽團/家庭咖,一團一團點名邀 | 最高價值:已有習慣,只缺更好場地;賣點=比客廳爽(乾淨、飲料、有人服務、不用洗牌收桌) |
| 創辦人人脈 | 高雄在地牌咖,直接邀 | 開店前親自跑 |
| **店員自帶牌咖** | 「會打牌、有牌友圈」寫進徵才條件 | **徵一個店員=獲得一個牌咖網絡**;朋友因她上班而來,信任天生;一石二鳥 |
| 創始會員預售 | 開幕前儲值優惠+「創始會員」身分(分級制度隱藏頂層)+永久專屬權益,限量 | 製造「現在加入才有」;預售款=開辦現金流 |

### 數字模型(以首店桌數推算)
```
目標:開幕首月黃金時段穩定 N 桌
→ 每日人次 ≈ N × 4
→ 以每人每週來 1–2 次計,所需活躍池 ≈ 每日人次 × 5
→ 種子池(含流失緩衝 ×1.5)≈ 活躍池 × 1.5
範例:8–10 桌店,黃金時段目標 4–5 桌
→ 16–20 人次/天 → 活躍池 80–100 → 種子池 100–150 人
→ 其中至少 10–15 個「完整四人團」
```
**開幕日 KPI:種子池 100–150 人、10–15 個完整團。**(實際桌數定案後按公式重算)

## 打法二:集中時段,不要攤平(需求密度管理)

**冷啟動期自殺行為 = 全天營業隨客人來。** 稀疏需求攤 12 小時,任何時刻都湊不滿。

- 開明確「**開桌場次**」班表(如:平日 14:00 婦女場、19:30 晚場、週末下午場)——像健身房團課,客人是「報名週二下午場」,不是「來碰運氣」。
- **成桌率不是靠人多,是靠需求密度**:四散客分散四小時永遠湊不成;壓進同一場,一桌就成。
- 配桌系統開幕版照「場次制」運作:LIFF 報名 → 前一天機器人提醒 → 湊齊通知。即時配桌是會員量大後的型態,冷啟動期不適用。
- **製造滿感**:寧可 6 桌天天滿,不要 10 桌空一半。「滿」是行銷,空桌感是毒藥;前期可圍起部分區域標「即將開放」。

## 打法三:保證開桌承諾(冷啟動期的核心產品)

對種子客人的明確承諾:「**報名場次,來了就有牌打。**」手段按成本排:

1. 場次滿四人才確認(系統自動)
2. 差一人 → 三缺一推播給段位/時段相符會員(機器人)
3. 仍差 → **店員補位**(店員必須會打牌的原因)。冷啟動期代打佔比可達 2–3 成——這不是人力浪費,是**買「沒有人白跑」口碑**,開幕期最值的行銷支出
4. 真開不成 → 提前通知別出門 + 補償(飲品券/點數),失望管理

**白跑一次的殺傷力 >> 補位一場的成本。** 中高齡客群口碑傳播快,前 90 天每次體驗都在定義名聲。

---

## 打法四:90 天把「活動咖」織成「固定咖」

開幕熱度撐 30 天,之後靠習慣。目標:90 天內讓種子客形成「**週幾下午是我的麻將時間、那桌是我的人**」。

- 系統觀察常同桌者 → 主動推「把這三位設成固定咖?以後一鍵揪」(好友牌咖系統 Day 1 上線的原因)
- 固定場次+固定的人=習慣迴路;成形即離不開——**網路效應護城河開始澆築的時刻**
- 推薦獎勵(湊咖獎)此時啟動:讓已成形的團長出新團
- 第 60–90 天辦**首場店內友誼賽**:給常客「我們是一個社群」的儀式,也是段位系統起點

## 時間表

| 階段 | 重點 | KPI |
|---|---|---|
| 開店前 90–30 天 | 招團(現成團/店員自帶/創始預售) | 種子池 100–150、完整團 10–15、預售儲值額 |
| 開店前 30–0 天 | 場次班表定案、報名/推播/補位系統演練、店員牌技與代打訓練 | 開幕首週場次預約滿桌 |
| 開幕–30 天 | 場次制營運、保證開桌、製造滿感(開 6 留 4) | 成桌率 >90%、白跑率 ≈0 |
| 30–90 天 | 織固定咖、推薦獎勵啟動、首場友誼賽 | 7日回流率、固定團數、店員代打佔比下降 |

## 冷啟動期只盯四個指標
1. **成桌率**(報名者有打到的比例)
2. **白跑率**(到店沒打到)
3. **7 日回流率**
4. **固定團數量**
其他數字前 90 天都不重要。
