# MIGI 咪吉麻將 — 戰略備忘 v1.0(三大隱憂與校準)

> 本文件記錄創辦人提出的三個核心隱憂與梳理結論。這三題互為因果,合起來是整個事業的戰略骨架,**優先級高於所有功能規格**。

---

## 隱憂一:商業模式一推出就被複製,沒有護城河?

**殘酷事實**:看得到的都抄得走——粉紅裝潢、小熊 IP、會員分級、留存玩法全是「表層」。若護城河是這些,等於沒有護城河。

**真護城河 = 別人抄了也追不上的累積**,藏在三道牆:

| 牆 | 內容 | 為何抄不走 |
|---|---|---|
| **數據累積** | 牌譜、會員行為、配桌偏好,每天在長 | 數據是時間函數;競品 Day 1 = 零。前提:要把數據變成客人有感的價值(精準配桌、AI 教練、年度回顧),否則是死資產 |
| **網路效應(人鎖人)** | 好友/牌咖/姊妹團——客人來是因為「她的牌咖在這」 | 關係要搬就得整群搬,且段位/成就/回憶歸零。**人際關係的遷移成本是抄襲者跨不過的牆** |
| **品牌信任** | 「MIGI=女生安心打牌的地方」的認知 | 信任=時間+口碑,裝潢堆不出來 |

**第四道(速度)**:平台化(系統授權給現有麻將館)。趁競品反應前佔住通路,你就不是一家店,是**麻將產業的基礎設施**——抄一家店容易,抄一個已佔住節點的平台難一個量級。

**結論:不護表層(防不住),猛砸三道牆——加深數據、鎖住關係、佔住通路。點子會被抄,累積抄不走。**

## 隱憂二:麻將人口男 8 女 2,全做女性會不會擋掉男性?

**核心洞察(創辦人,正確)**:「所有男生都想跟女生打麻將。」男性現在去的是菸味、賭博、清一色男性的傳統館;**「有女生、乾淨、能光明正大去」的場域對男性吸引力,大於又一家男性麻將館**。女性友善是釣男性的鉤子,不是放棄男性。

**真實風險**:執行太「少女」,男性站門口就不敢進。

**修正:從「女生的麻將館」→「乾淨、安心、有質感的麻將空間,女生也愛來」**
「連女生都愛來」= 對男性的品質保證(不是傳統賭場),而非排除宣言。

### 各接觸點的平衡執行
| 接觸點 | 修正 |
|---|---|
| 標語 | 「Girls Play Together」降為子線,主張改中性有態度(乾淨/安心/質感/競技) |
| 空間 | **精品粉非少女粉**:大地色/奶茶/暖白為主體、粉當點綴;小熊精緻化(LINE Friends 感非兒童樂園);對標 %Arabica/無印+一點粉,不對標 Etude House。檢驗:40 歲男性走進來覺得「有品味」而非「我女兒會喜歡」 |
| 會員系統 | **雙線並行**:養成/社交線(小熊、裝扮、姊妹團)偏女性、可無視;競技/段位線(段位、賽事、牌譜分析)做硬核——**男性更吃競技**。同一系統,各取所需 |
| 餐飲 | 補中性線:黑咖啡、無糖茶、鹹食正餐,男性有「能正常點」的東西 |
| 配桌 | **平衡的技術核心**:純女性場+混合場、混合場比例上限(防三男圍一女)、女性可設偏好。**女性有控制權→有安全感→願意來→男性才有「跟女生打牌」的機會** |

### 紅線(決定品牌長短命)
**女性必須是真心服務的核心顧客,不能是吸引男性的誘餌。**
- 誘餌思維 → 女性被物化而逃、品牌崩、法律道德風險
- 核心顧客思維 → 服務到安心開心,「這裡有一群快樂自在的女性常客」這個**事實**自然吸引男性
- **男性是被健康的女性社群氛圍吸引;你經營的是女性的快樂,男性是副產品受益者。**

### 定位定稿
> MIGI:乾淨、安心、有質感的麻將空間。核心服務女性(社交/養成/安心),競技線兼容男性(段位/賽事/硬核),空間走中性精品調,配桌機制保障男女共處的舒適與安全。女性的快樂是磁鐵,不是誘餌。

## 隱憂三(校準):麻將客人 99% 的誘因 = 有牌打,App 誘因只是輔助

**實務鐵律(創辦人)**:湊不出桌,其他一切歸零。傳統館沒 App 沒裝潢客人照去——因為去了有牌打;你的店再漂亮,連三次三缺一,客人第四次就不來。

**翻成系統語言:MIGI 的核心產品 = 保證成桌率**(想打時,可接受時間內湊到一桌合適的人)。

### 優先序重排
1. **生死線:配桌引擎 + 牌咖網絡 = 成桌率**
   - 配桌引擎是**本體**非模組之一;好友/牌咖**升格為配桌的一部分**(固定咖一鍵開桌、三缺一推播、「妳的牌咖正在找人」)
   - 訊息機器人主動推播 = 成桌率放大器(傳統館做不到、你做得到)
2. **降低「湊不到」的失望成本**:候補透明、湊齊才出門(LINE 通知,消滅白跑)、員工代打保桌不散
3. **才是留存引擎十六個**:在「有牌打」被保證的前提下,讓客人選你、來更勤、多消費——差異化放大器,非吸客主力

### 冷啟動(會員少最難湊桌)
店員代打、固定時段「保證開桌場」、地推揪團——成桌率撐起來之前,系統再漂亮都是空的。

## 三題串成一條因果鏈(整個事業的骨架)

> **配桌系統+牌咖網絡(本體:保證有牌打)
> → 女性友善定位(讓牌咖池差異化:別家湊大叔桌,你湊得出乾淨混合質感桌)
> → 留存引擎(讓人黏著、頻率變高)
> → 數據累積(配桌越來越準)
> → 網路效應+品牌+通路 = 護城河
> → 飛輪轉起來**

誘因是有牌打 → 成桌率靠牌咖網絡 → 網絡=護城河 → 女性策略=供給差異化。三個隱憂是同一件事的三個面。
