# MIGI 咪吉麻將 — 聯名商品區規劃 v0.1

> 核心定位:聯名商品區 ≠ 賣場角落,而是 **實體變現出口 + 打卡點 + 段位炫耀牆** 三合一。
> 目標體驗:一進門就想拍 → 拍了就想買 → 買了還想升段位買更好的。

---

## 1. 三重角色

| 角色 | 作用 |
|---|---|
| 零售區 | 賣商品賺錢(自有 IP 毛利最高) |
| 打卡牆 | 網美拍照 → 商品自動入鏡 → 免費宣傳 |
| 段位展示處 | 把「打得好才買得到」實體化 → 刺激消費與競技 |

---

## 2. 空間規劃

### 2.1 位置:動線必經 + 等待區
- 放在 **入口 / 結帳區 / 等待配桌區**。
- 理由:配桌候補要等 → 等待時間 = 最佳逛街時間;入口 = 進門第一眼 + 離店最後一眼雙重曝光。
- 不要藏角落。

### 2.2 分區:按「段位解鎖」分層陳列(MIGI 獨門)
| 層 | 陳列方式 | 商品 |
|---|---|---|
| 開放區 | 平台/開架,人人可買 | 小熊周邊、基本麻將尺、Tee、飲料杯 |
| 段位解鎖區 | 玻璃櫃 + 特殊燈光 | 金牌熊以上才能買的限定款、編號麻將尺 |
| 雀神專屬區 | 最頂、最稀有位置 | 當季雀神同款、限量聯名 |
- 視覺做出「越往上越稀有」層次 → 低段位客人看到買不到的,產生升段動力。
- **把競技系統變成消費引擎**。

### 2.3 打卡牆:聯名主視覺
- 一面牆 = 聯名主題大型打卡背景(小熊×聯名 IP 巨型公仔/霓虹/插畫),旁邊即商品。
- 拍照 = 商品入鏡 = 免費廣告。
- **隨聯名檔期更換** → 製造「限定、趁現在」急迫感。

### 2.4 體驗陳列:商品可玩
- 麻將尺/牌/周邊設可試用體驗台(摸材質、試手感)。
- 「欸這個好可愛你看」的互動帶動購買,契合女生聚會場景。

## 3. 聯名策略(找誰聯名)

| 類型 | 目的 |
|---|---|
| IP 聯名(三麗鷗/插畫家/卡通角色) | 借粉絲拉新客 |
| 在地聯名(高雄品牌/文創) | 地域獨特性、媒體話題 |
| 異業聯名(美妝/服飾/飲料) | 精準打女性客群 |
| 自有 IP(MIGI 小熊周邊) | 毛利最高、最該主推 |

## 3.5 具體商品清單(可販售品項)

> 三維度:毛利 × 稀缺性 × 系統綁定。標示適合開放區或段位解鎖區。

### ① 麻將本體周邊(最扣題、品類獨佔)
- 麻將尺:基本款(開放)/ 編號限定款(段位解鎖)/ 聯名款
- 隨身迷你麻將、麻將造型鑰匙圈/吊飾
- 個人牌尺收納袋(小熊刺繡)
- 麻將牌面磁鐵、貼紙(低單價、好收集)

### ② 小熊 IP 周邊(毛利最高、零售主力,無授權金)
- 小熊娃娃(大隻鎮店打卡 / 小隻好帶走)
- 小熊抱麻將牌公仔(招牌造型)
- 馬克杯、保溫瓶、隨行杯
- 襪子、髮飾、小包、鏡子(女性日常小物)
- 小熊 LINE 貼圖(線上、零庫存、純利)

### ③ 服飾配件(穿出去=移動廣告)
- Girls Play Together Tee / 帽 T
- 托特包、帆布袋(印小熊+麻將)
- 棒球帽、髮帶、襪子
- 聯名款服飾(限定)

### ④ 段位/成就解鎖品(競技變消費,MIGI 獨門)
- 編號限定麻將尺(No.001…,金牌熊以上可買)
- 雀神同款(當季賽季限定)
- 段位徽章/胸針(實體段位象徵,可別包上炫耀)
- 冠軍紀念牌(賽事得獎者專屬)

### ⑤ 文具/生活小物(低單價、衝動購買、伴手禮)
- 麻將牌面餅乾盒、小熊餅乾(呼應餐飲線)
- 筆記本、貼紙、明信片、月曆
- 環保杯、午餐袋、雨傘
- 撲克牌/桌遊(延伸桌邊娛樂)

### ⑥ 聯名限定(檔期話題、拉新客)
- 三麗鷗 × MIGI、在地文創 × MIGI、美妝/飲料品牌 × MIGI
- 限定檔期、限量編號、賣完不補

### 上市優先序
| 優先 | 品項 | 理由 |
|---|---|---|
| 第一波 | 麻將尺(基本+編號)、小熊娃娃、Tee、托特包 | 扣題、高毛利、移動廣告 |
| 第二波 | 小熊日常小物、LINE 貼圖、餅乾禮盒 | 衝動購買、零庫存、伴手禮 |
| 第三波 | 段位解鎖編號款、雀神同款、徽章 | 待段位系統上線綁定 |
| 之後 | 聯名限定 | 待品牌有名氣後談好對象 |

### 商品設計三原則
1. 能編號的就編號(No.001…)→ 稀缺、收藏、炫耀。
2. 能綁段位/成就的就綁 → 競技變消費動力。
3. 能印小熊+麻將的就印 → 每件商品都是行走的廣告。

## 4. 與系統串接(回扣既有設計)

- **段位解鎖**:商城 `min_dan` 欄位控制誰能買 → 線上 LIFF 商城與實體店**同一套庫存、同一解鎖規則**。
- **點數結算**:全程點數購買,呼應「桌面不見現金」鐵律。
- **成就綁定**:部分品綁成就(如「百勝熊」才能買的編號款)→ 留存系統 × 零售綁一起。
- **限量編號**:聯名品做流水編號(No.001…)→ 稀缺 + 收藏 + 社群炫耀。

---

## 5. 空間邏輯總結
> 聯名區放在等待動線上,用**段位分層陳列**(開放→解鎖→雀神專屬),配一面**隨檔期換的打卡牆**,商品可試玩,全程點數買、線上線下同庫存。
> → 從「賣場」升級成「會自己賣貨、自己宣傳、還刺激打牌」的複合空間。
