# 埋點事件字典

**【這是什麼】** 目前已埋的所有追蹤事件、附帶維度、以及常用查詢。
**【何時讀】** 要新增事件、看行為數據、或排查線上錯誤時。

---

## 架構

- 前端統一呼叫 `track(event, props)`（`src/lib/analytics.js`），fire-and-forget 不阻塞 UI
- 後端 `log_app_event_tx` → `app_events` 表（append-only + 防刪觸發器）
- 每筆自動帶 `app_version`（build 時注入的版本號，如 `v0714-1958`）
- 開關：`ANALYTICS.toConsole / toSupabase / toPostHog`

---

## 事件清單

| 事件 | 觸發點 | 附帶維度 |
|---|---|---|
| `app_open` | 開啟 App | — |
| `page_view` | 切 tab / 啟動 | `page`, `from`(launch/tab) |
| `notif_open` | 點鈴鐺 | — |
| `like_player` / `unlike_player` | 收桌視窗按讚/取消 | `target`, `from`(settle) |
| `buddy_invite_sent` | 發牌咖邀請 | `target`, `from`(**settle / recent / profile** 三入口分開統計) |
| `buddy_invite_accepted` / `_rejected` | 回應牌咖邀請 | `from` |
| `table_invite_sent` | 揪桌邀請送出 | `target`, `mode`(**direct / auto_after_open**) |
| `table_invite_accepted` / `_rejected` | 回應揪桌邀請 | — |
| `match_join` | 加入/開桌成功 | `store`, `stake` |
| `app_error` | **自動**（未捕捉錯誤） | `kind`(react/js/promise/resource), `message`, `stack`, `at` |

**滲透率**：`markAppActive()` → `members.last_app_active_at`

## 錯誤自動上報（取代臨時 debug）

`src/main.jsx` 常駐監聽 JS 錯誤、Promise 錯誤、**資源載入失敗**；
`ErrorBoundary` 捕捉 React 渲染錯誤並顯示友善畫面（不再白屏）。
同次開啟最多上報 10 筆，防 error loop 灌爆資料表。

**以後遇到白屏，先查這個，不用再要 debug 版 index.html：**
```sql
select props, created_at from app_events
where event = 'app_error' order by created_at desc limit 20;
```

## 常用查詢

```sql
-- 最近事件流
select event, props, member_id, created_at
from app_events order by created_at desc limit 20;

-- 每日活躍（已自動排除測試帳號）
select * from v_app_daily_active order by biz_date desc;

-- 社交功能實際使用量
select event, count(*) from app_events
where event like 'buddy_%' or event like 'table_%' or event = 'like_player'
group by event;

-- 加牌咖三個入口的轉換比較
select props->>'from' as 入口, count(*)
from app_events where event = 'buddy_invite_sent' group by 1;
```

**注意**：`app_events` 前端讀不到（RLS 全擋），要在 Supabase Dashboard 以 service_role 身分查。
