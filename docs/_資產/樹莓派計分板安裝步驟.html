樹莓派計分板安裝步驟

樹莓派 5 ＋ 7 吋觸控螢幕，開機自動全螢幕打開 table.migi.tw。跟平板是同一份計分板，配對、教學模式、自動更新都照用。

這份還沒在實機走過。「轉成橫的」與觸控方向那一步最可能要調，走到那裡把實際情況告訴 Claude。

0要準備的東西

樹莓派 5（4GB）2GB 也開得動，4GB 比較從容
官方 27W USB-C 電源用手機充電器會跳低電壓、畫面當掉
microSD 32GB 以上A2 等級比較快
官方主動散熱器整晚開著要散熱
7 吋觸控螢幕官方 Touch Display 2，或 Waveshare 7-DSI-TOUCH-A
USB 鍵盤、滑鼠只有設定時用

1把系統燒進 SD 卡（在電腦上）

  1. 安裝 Raspberry Pi Imager（raspberrypi.com/software）
  2. 裝置選 Raspberry Pi 5 → 作業系統選 Raspberry Pi OS (64-bit)（有桌面的）→ 選 SD 卡
  3. 選「編輯設定」：主機名稱 migi-a1（照桌號）；使用者名稱與密碼自己設、記在帳密本；店裡的 Wi-Fi、國家 TW；時區 Asia/Taipei
  4. 寫入，等驗證完再拔卡

2接螢幕與電源

  1. 螢幕排線接樹莓派的 DSI 接頭（兩個窄扁接頭任一個），方向照螢幕說明
  2. 螢幕供電：杜邦線接 5V（第 2 腳）與 GND（第 6 腳）
  3. 插 SD 卡、接鍵盤滑鼠，最後才插電

3第一次開機、更新

左上選單 → 附屬應用 → 終端機，輸入（在樹莓派上）：

sudo apt update && sudo apt full-upgrade -y

跑完重開機：

sudo reboot

4螢幕設定

  • 不要自動關螢幕：終端機輸入 sudo raspi-config → Display Options → Screen Blanking → No
  • 轉成橫的：左上選單 → 偏好設定 → Screen Configuration → 對 DSI-1 按右鍵 → Orientation 選 90 或 270 → 套用
  • 轉完用手指點點看：位置對不上就是觸控沒跟著轉，先記下來

5配對到某一桌

  1. 在樹莓派打開 Chromium，網址打 hq.migi.tw
  2. LINE 登入（用手機 LINE 掃螢幕上的 QR）
  3. 「智慧計分板」頁替這一桌產生配對碼
  4. 複製「網址（可複製）」，開新分頁貼上、按 Enter
  5. 出現計分板畫面就配好了
  6. 回後台登出、關掉那個分頁

6開機自動全螢幕

先查 Chromium 的指令名稱（印出哪個就用哪個）：

which chromium chromium-browser

建立自動啟動檔：

mkdir -p ~/.config/labwc && nano ~/.config/labwc/autostart

貼上這兩行，Ctrl+O、Enter 存檔，Ctrl+X 離開：

sleep 5
chromium --kiosk --noerrdialogs --disable-infobars --disable-session-crashed-bubble --password-store=basic https://table.migi.tw/ &

不可以加 --incognito：無痕模式每次開機都會把配對清掉。

sudo reboot

開機直接是全螢幕計分板就完成了，拔掉鍵盤滑鼠。

7平常使用

  • 插電就好，約 30～60 秒出現計分板
  • 計分板改版不用動樹莓派，閒置時會自己重新整理
  • 要退出全螢幕：接鍵盤按 Alt+F4
  • 一兩個月做一次第 3 步的更新

8遇到問題

畫面閃、出現閃電圖示電源不夠力，換官方 27W
開機沒出現計分板接鍵盤檢查第 6 步的檔案與指令名稱
每次都要重新配對第 6 步誤加了 --incognito
點的位置對不上第 4 步換 90／270 試
螢幕會變黑第 4 步 Screen Blanking 選 No
