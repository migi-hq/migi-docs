消費進度條 · 文案五版

排版固定（同一行 ＋ 條），比的是怎麼把「等級名」與「折扣」綁在一起說。 資料：累積 $400、下一階焦糖布丁（門檻 $6,000、95 折）、還差 $5,600。

🔴 一個容易漏掉的衝突：「焦糖布丁」同時是菜單上的甜點（60 元，《首店餐飲籌備》1-2）。 在錢包頁上寫「升焦糖布丁」，會被讀成「買一個布丁」。
⇒ 好的寫法必須讓人一眼知道那是一個等級的名字，而不只是把折數放在旁邊。

W1 · 現行（問題版）

三個事實平鋪，沒有講關係
我的點數 0 點會員等級: 珍珠奶茶
累積 $400 再 $5,600 升焦糖布丁 · 95 折
✗ 「焦糖布丁」與「95 折」用一個「·」連著，那個點號沒有語意。
✗ 讀起來也可能是「花 $5,600 買布丁送 95 折」。

W2 · 加「會員等級」四個字

最直白，把類別講出來
我的點數 0 點會員等級: 珍珠奶茶
再消費 $5,600，升上會員等級 焦糖布丁，結帳 95 折
✓ 歧義沒了。
✗ 但「會員等級」四個字**上面那顆膠囊已經講過一次** —— 同一個畫面講兩次， 而且這一行變成兩行。

W3 · 講因果（之後…都）

把折扣說成升級的結果
我的點數 0 點會員等級: 珍珠奶茶
再消費 $5,600 升上 焦糖布丁， 之後結帳都 95 折
✓ 「之後…都」把關係說死了 —— 折扣是升級的結果，不是附贈品。
✓ 等級名做成膠囊，一眼看出「那是一個名字」。
✗ 兩行；而且「之後都」在長期優惠上是承諾，用詞要小心。

W4 · 只講好處（不提名字）

折數才是動機
我的點數 0 點會員等級: 珍珠奶茶
累積 $400 再 $5,600 就能升級，結帳 95 折
✓ 完全沒有歧義，而且一行放得下、長等級名也不會擠。
✗ 丟掉了「焦糖布丁」這個名字 —— 而那是品牌刻意設計的階梯， 客人談論等級時用的就是那些甜點名。

W5 · 標籤化（下一階 ＝ …）

用「下一階」當定語，名字與好處綁一起
我的點數 0 點會員等級: 珍珠奶茶
下一階　焦糖布丁 95 折 還差 $5,600
已累積 $400
✓ 「下一階」兩個字把整組話定義好了 —— 名字與折數黏在一起， 而且不用寫「會員等級」（上面膠囊已經建立脈絡）。
✓ 名字與折數同色塊、緊鄰 ⇒ 讀成「焦糖布丁＝95 折」。
✗ 多一行「已累積 $400」（+18px）。

我建議 W5，其次 W3

你指出的問題本質是：「·」這個點號沒有語意 —— 它把兩個事實放在一起，卻沒說它們是什麼關係。

W5 用「下一階」這個定語解決它： 下一階 [焦糖布丁] 95 折 —— 名字與折數在同一個視覺群組裡， 讀出來就是「下一階叫焦糖布丁，它給 95 折」。 而且不必寫「會員等級」四個字，因為上面那顆膠囊已經建立了脈絡。

🎯 它順帶解掉那個甜點撞名的問題：「下一階」讓「焦糖布丁」不可能被讀成一個商品。

⚠ W4 是最安全的（零歧義、一行、長名也不擠），但它丟掉了等級名 —— 而那些甜點名是品牌刻意設計的階梯，客人講的就是那個。只有在版面真的不夠時才退到 W4。
🔴 不建議 W2：「會員等級」四個字在同一個畫面上會出現兩次。
⚠ W3 很好但那句「之後結帳都 95 折」是一個承諾 —— 而總部今天改得動折扣（剛做的那一頁）。用詞上「都」比「享」硬。
