token 加深一階 · 候選值

每一欄是把 token 的值換掉之後整塊會長什麼樣（用 CSS 變數覆寫， 不是各自手改顏色）—— 所以你看到的就是改 token 的實際效果。

🔴 這兩件都不是「改一處」。
· --gray-1 在 migi-web 出現 187 次（POS 與 admin 另計）—— 那兩句小字沒有共用元件，共用的是這個 token。
· --brand-tint ＋ 1px --brand 這個組合有 4 處 （NavRow、配桌進度卡、配桌彈窗、會員等級卡）＋ admin 1 處。 只改一張就是硬規則 13.8 禁止的「第三種粉」。

⚠ 所以正解是改 @migi/assets 的 token 值， 流程是：tokens.json → npm run build → 打 tag → 三個 repo 各自 bump 再 npm install。
