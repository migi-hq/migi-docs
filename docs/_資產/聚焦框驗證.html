墨底（--ink）—— 兩層環真正發揮作用的地方

深色膠囊 兩種都要能看見 —— 白的與深的。
為什麼「2.33 未達」不是一個沒解決的問題。
環是兩層的，由內而外：元件 │ 白 2px │ 深色 2px │ 背景。
要看得見，只需要其中任何一條交界達到 3:1，而白與深色之間永遠是 6.02 —— 那條交界不受背景影響。
· 深色元件站在墨底 → 內側的「元件↔白」高對比，看得見
· 白色元件站在墨底 → 內側的「元件↔深色」是 6.02，看得見
🔴 單層環才會出問題，那正是加第二層的理由。

不該有框的：表單欄位

🔴 規則刻意不含 input / select / textarea。
POS 的搜尋框是「邊框在外層容器、input 自己 border:none」，
先前在全域加 outline 把它變成粉色粗框，那段警告還留在 index.css 裡。

白圈 ↔ 深色圈（兩層之間） 6.02 ✅ 不受背景影響，永遠成立

🎯 整個環是不是看得見，看的是「任何一條交界」，不是每一條都要達標。
那條 2.33 是設計已經處理掉的東西，不是待辦事項 —— 單層環才會在墨底上消失，而這正是加第二層的理由。
