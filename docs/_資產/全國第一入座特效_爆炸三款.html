全國第一登場：爆炸光點三款

都從 A「王座登場」出發：斜光拿掉，換成從頭像炸開的光點、衝擊波與閃白，再加上一句強調。三款的爆法與那一句各不同，句子可以互換。播完一樣縮回對家卡片，卡片角落留一顆「全國第一」。名字是範例，平板實際尺寸等比例縮小。

1

強者登場

一次大爆炸：閃白 → 頭像彈出 → 光點與兩圈衝擊波 → 餘燼往上飄
強調那一句「強者登場」小標＋你即將面對的是全國第一名
手感乾淨、像頒獎，爆一次就收
第一名自己那台「強者登場」＋「全場都在看你」
每 9.5 秒自動重播
2

已入座

先吸後炸：光點從四周吸進中心、光球脹大 → 炸開＋畫面震動 → 「已入座」章蓋下去再震一下
強調那一句大字旁邊蓋一個已入座章，下面你即將跟第一名對戰
手感最震撼，有「降臨」的蓄力感
第一名自己那台章改成「就位」，下面「三位挑戰者已入座」
每 9.5 秒自動重播
3

連環爆

左、右、中間依序炸開像煙火，中間最大；之後光點像金粉一樣往下灑
強調那一句從左邊衝進來一條：「全國第一 已入座」小標＋這一場，你的對手是全國第一
手感最熱鬧，像慶典
第一名自己那台「全國第一 已入座」＋「這一場，三位都是來挑戰你的」
每 9.5 秒自動重播

強調句可以換成這些（三款都通用）

  • 你即將面對的是全國第一名
  • 你即將跟第一名對戰
  • 這一場，你的對手是全國第一
  • 全國第一 已入座
  • 強者登場／王者降臨（適合當小標）

都只講「對戰、對手、挑戰」，不碰輸贏與積分的錢味（賭博紅線用詞）。
