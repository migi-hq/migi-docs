教練熊說：✦ AI 即時分析

再打 16 局，教練熊就能幫你看出你的打牌習慣。

已記錄 4 / 20 局（一場通常 8–16 局）

少於 20 局不寫分析：只打 4 局就說「放槍偏多」，很可能只是運氣。這一張不用叫 AI，費用是零。

本狩 岡五郎：計分板記錄 4 局

它怎麼運作

  1. 算數字（資料庫）：每打完一場，從計分板紀錄算這個人最近 100 局的胡牌率、放槍率、自摸、當莊表現、一將最後兩局的放槍、平均與最大台數，並跟全店平均比。
  2. 挑重點（資料庫）：只挑差距最明顯的一兩項給 AI，不把全部數字丟過去。
  3. 寫成句子（AI）：一支 Edge Function 把那幾個數字交給 Claude 的小模型，寫成兩三句教練口吻的話。規定：只能用給它的數字、不能編、不能出現賭博用詞（贏錢、下注之類），講缺點也要給一句鼓勵。
  4. 存起來：寫好的句子存在資料庫，成績頁打開直接讀，不會每次打開都叫 AI。

費用：一句大約新台幣 0.05–0.1 元，一個客人一場一次。100 位客人每週打 2 場，一個月約 40–80 元。

寫不出來（AI 服務掛了）時，這一塊不顯示，不會顯示舊的或假的句子。

做不到的

「聽牌不夠大就打安全牌」這種該打哪一張的建議，要知道手上有什麼牌、每一次打了哪張，那是牌譜辨識（攝影機），現在沒有。教練熊現在只能講「什麼時候容易放槍、胡牌靠什麼」，不能教打牌選擇。

開工前需要你準備的

  • 一把 Claude API 金鑰（Anthropic 開發者帳號，要綁信用卡、預付額度）。放進 Supabase 的 Secrets，名字叫 ANTHROPIC_API_KEY，不要貼進對話。
  • 確認比較基準：預覽用的是全店平均。真客人多了之後，改成同段位平均比較公平（現在每個段位的人太少）。
