次要文字灰要不要加深

現在的 --gray-2 是 #88827E，對白底 3.79，而一般大小的文字門檻是 4.5。 它在會員 App 用了 197 處，其中 123 處同一行就寫著小字級 —— 也就是這個灰 幾乎從來沒有用在大字上，每一處都在門檻以下。
下面每一欄是同一批**真的文案、真的字級**，只有顏色不同。

↓ 改成 C：gray-2 往 gray-1 靠過去，兩者會比較難分

🔴 歪掉是躲不掉的，不是這個值挑得不好。
從 4.5 到 --ink 之間放不下四個看得出差別的灰。 這條階梯最多只能有 三階 是合格的內文色 —— 所以真正的決定不是「挑哪個值」，是 「--hint 從此不當內文色用」。
✅ 好消息：--hint 在會員 App 只用了 4 處、其中 2 處是文字色， 改起來很小。它本來就叫「提示文字」。

④ 改了會動到誰

三端吃同一個 @migi/assets（都在 v1.9.0），所以 POS 與總部後台也會一起變深。方向是「字更清楚」，不會弄壞版面， 但那是三個 App 同時的視覺變動。
流程：改 tokens.json → npm run build → 打 v1.10.0 → 三端 package.json bump → npm install。
