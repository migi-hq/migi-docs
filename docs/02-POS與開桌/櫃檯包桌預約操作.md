# 櫃檯包桌預約操作（店員教育訓練）

> 建立 2026-09-13。對應 `migi-pos` 的「包桌預約」頁與 `bookings` 那一批 RPC。
>
> 🔴 **這一份是寫給店員看的，不是寫給工程師看的。**
> 改它的時候不要放欄位名、函式名、SQL、狀態代碼。
> 一句話讀不懂就是寫壞了 —— 真正在讀它的人站在櫃檯、手上有客人。
> 技術細節在 `docs/03-會員App與社交/牌咖團與包桌.md`。

---

## 這一頁在哪

**POS 側邊欄 → 現場 → 包桌預約。**

它只回答一件事：**今天誰會來、幾點、幾桌。**

- 一次看一天。上面有「昨天／今天／明天」三顆，右邊那格可以挑任何一天。
- 每 30 秒自己更新一次，不用重新整理。客人可能在路上用手機取消。
- 左上角會寫現在看的是哪一間店。**看不到預約的時候第一個要檢查的就是它。**

---

## 🔴 最重要的一件事：即時桌況看不到預約

**桌況那一頁完全不知道預約的存在。**

晚上七點有五桌預約，下午三點的桌況看起來還是全空。
如果你只看桌況就把最後幾張桌開給現場客人，晚上那五桌就沒有地方坐。

→ **答應現場客人之前，先切到包桌預約看一眼今天剩下的時段。**

這不是系統壞了，是它今天就是這樣設計的：預約佔的是**容量**不是某一張桌，
桌號是客人到店那一刻你才指定的。所以在他走進來之前，沒有任何一張桌被標記。

---

## 客人那一端看到什麼

客人在會員 App 的「牌咖」分頁，進到自己的牌咖團，按「預約包桌」。

他能選的只有這些：

| | 他能選什麼 |
|---|---|
| 門市 | 任何一間 |
| 日期 | 最早 **30 分鐘後**，最遠 **90 天內** |
| 時長 | 只有 **2 小時／5 小時／整天** 三種 |
| 桌數 | 1 到 10 桌 |
| 備註 | 隨他打，例如「我們大概 7 個人、想要靠窗」 |

系統會擋掉的（客人會直接看到一句話，不會訂成功）：

- 不到 30 分鐘之後的，會請他直接到櫃檯
- 同一個團在同一個時段已經訂過一筆
- 那個時段桌不夠。畫面會告訴他**還剩幾桌**，所以他可能會改訂少一點

🔴 **今天沒有牌咖團的客人訂不到。** 入口在團的頁面裡。
他要訂只能請他先建一個團，或是直接現場開桌。

## 一筆預約的五種狀態

| 畫面上寫 | 意思 | 還能動嗎 |
|---|---|---|
| （沒有膠囊，右邊有兩顆按鈕） | 還沒處理 | ✅ 要你處理 |
| **已入座** | 你已經帶他到桌了 | ❌ |
| **已取消** | 客人自己取消，或你按了取消 | ❌ |
| **沒有出現** | 你按了「時間到了沒出現」 | ❌ |
| **過了沒處理** | 時間整個過完了，沒有人碰它 | ❌ |

「過了沒處理」是系統自己標的，**不是你的錯誤**，但它代表那筆從頭到尾沒人理。
它算的是**結束時間**：訂五小時的話，開始五小時之後才會變成這個。

---

## 你能做的三個動作

### 帶到桌

客人到了 → 按「帶到桌」→ 選一張桌。

🔴 **這一步不會開桌，也不會收錢。**
它只是把這筆標成已入座並記下桌號。
**檯費仍然要照平常走：即時桌況 → 開桌設定 → 結帳。**
按完之後畫面下面那句提示也會提醒你。

⚠ **一筆預約只記得住一張桌號。** 客人訂三桌的話，另外兩張你要自己安排、自己記得。

⚠ 只能選**這間店**的桌。選到別間的會被擋下來。

### 客人有說要取消

他打電話來、傳訊息、或當面說不來了。

### 時間到了沒出現

時間過了、人沒到、也聯絡不上。

🔴 **這兩顆不要混用。** 兩個都會把那個時段的桌位放回去給別人訂，
差別只有一個：**會不會算成爽約。**

爽約率是開放預約的店唯一會後悔沒有記的數字。
全部按「取消」的話，這個數字永遠是零，而你就永遠不知道哪些客人一直放你鴿子。

## 櫃檯會遇到的情況

**① 客人說「我有訂」，但清單上沒有**

照順序檢查：

1. 左上角的**店名**對不對。他可能訂了別間。
2. **日期**對不對。跨午夜的訂位（例如昨天晚上十點訂整天）會在**昨天**那一頁。
3. 那筆是不是已經被標成已取消或沒有出現了。
4. 都不是的話，到「會員查詢」搜他的暱稱，確認是不是本人記錯。

**② 客人遲到**

**先不要按「沒有出現」。** 按下去那個時段的桌位就放回去了，
別人可能立刻訂走，而他十分鐘後就到了。

只要那筆還沒被處理，**時間過了你照樣可以按「帶到桌」**。
真的整個時段都過完了它才會自動變成「過了沒處理」。

**③ 客人想改時間或改桌數**

**系統沒有「修改」這個動作。** 只能取消再重訂。

⚠ 而客人**只能在開始時間之前自己取消**。
過了時間他的 App 會叫他跟門市說一聲 —— 那就是叫他來找你，由你在這一頁處理。

**④ 客人訂了三桌，但只來了四個人**

帶到桌之後，多的那兩桌**不會自己放回去**。
你確定他們用不到的話，那一筆已經是「已入座」了，改不動。
把那兩張桌當空桌用就好，系統不會擋你。

**⑤ 團裡其他人說「我不知道有訂位」**

🔴 **訂位之後系統不會通知團員**，這是刻意還沒做的。
只有訂的那個人知道。所以團名下面那個「某某某 訂」很重要 —— 那是你能找的人。

**⑥ 客人問「我的訂位會不會過期」**

不會有人主動提醒他。系統不打電話、不發簡訊、不推播。
時間到了沒來，就由你在這一頁按「時間到了沒出現」。

**⑦ 客人問可不可以先付訂金**

**沒有押金也沒有罰則**，系統完全沒有這個概念。今天不要收。

---

## 系統今天不會做的事（先知道，才不會以為壞了）

- 不會通知團員
- 不會提醒客人
- 不會在桌況上顯示預約佔位
- 不會自動開桌、不會自動算檯費
- 不會讓客人修改訂位
- 沒有押金、沒有爽約罰則
- 沒有牌咖團的客人訂不到

## 速查

| 問題 | 答案 |
|---|---|
| 最晚可以多久前訂 | 開始前 30 分鐘 |
| 最早可以多久前訂 | 90 天 |
| 時長有哪幾種 | 2 小時、5 小時、整天 |
| 一次最多幾桌 | 10 |
| 誰可以取消 | 訂的人，或那個團的團長 |
| 客人幾點之後不能自己取消 | 開始時間之後 |
| 帶到桌會收檯費嗎 | **不會**，要另外開桌 |
| 一筆預約能記幾張桌號 | **一張** |
| 桌況看得到預約嗎 | **看不到** |
