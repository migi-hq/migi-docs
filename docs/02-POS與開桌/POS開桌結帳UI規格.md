# POS 開桌結帳 UI 規格（定案）

> 這是什麼：POS 端「開桌設定頁」與「結帳頁」的視覺與互動定案規格，經 v4→v47 數十輪迭代確認。
> 什麼時候讀：要改動 POS 開桌／結帳畫面、或要把設計還原成基準時。設計基準檔為 `pos-v47.html`。

---

## 一、開桌設定頁（OpenSetupPage）

獨立整頁，Sidebar 隱藏。依序問六題，答完才能按下一步。

| 順序 | 問題 | 選項 |
|---|---|---|
| 1 | 模式 | 配桌（店家湊人・按將數）／包桌（客人揪團・按時段） |
| 2a | 打幾將 | 3 將 $150／2 將 $100　※配桌才問 |
| 2b | 預估時段 | 2 小時內 $400／2–5 小時 $600／5 小時以上 $800　※包桌才問 |
| 3 | 遊戲規則 | 台麻／美麻 |
| 4 | 花牌 | 無花／有花 |
| 5 | 積分級距 | 由 `list_stake_levels_tx` 撈，預設帶入第一筆 |

**包桌人數與付款方式不在此頁問** —— 客人還沒登記，問了沒有對象可選，改到結帳頁由店員邊加人邊決定。

底部主按鈕「開桌，開始收費」，六題答完才啟用。

## 二、結帳頁（OpenCheckoutPage）三欄骨架

**頂欄 72px**：`MIGI`(22px/900/.08em) │ 桌號(22px/900) 設定摘要(13px 灰) ⋯ 右「‹ 回到即時桌況」(14px/700 純文字)

**三欄**：座位 216px ／ 商品加購（一行三個）／ 結帳明細 420px

### 左欄 · 座位卡

```
右上 ✕（未結帳才有）
🐻 40px 正圓白底
名字（15px/800，超長截斷加 …）
點數（12px/700 灰）
              右側狀態標籤
```

狀態標籤三態：

| 狀態 | 文字 | 底色 |
|---|---|---|
| 尚未收款 | 未結帳 | `--rose` 玫瑰底白字（最醒目） |
| 被他人代付 | 代付中 | `--peach` 蜜桃粉底墨字 |
| 已完成 | 已結帳 | `--idle` 淺灰底灰字 |

**不顯示「由 XXX 代付」紅字** —— 標籤已表達同一件事，且該行是長名字撐爆版面的元凶。

### 中欄 · 檯費／商品加購

分類 pill（檯費／餐飲／點心／聯名商品），下方一行三個的商品卡。

**檯費卡與商品卡同一規格**：右上 `＋` 或數量徽章、品名、價格顯示「150 點」。
檯費卡點擊不加入購物車（份數由代付關係決定，明細區自動帶入），但右上徽章會顯示目前份數。

### 右欄 · 結帳明細（由上而下）

```
會員條（蜜桃粉底）
餘額列（含「儲值」按鈕）
─────────────────
檯費　　　　×N　$450      ← 固定，份數鎖定
[ 代付其他人（2）    › ]   ← 虛線玫瑰框
[ 展開的勾選列表 ]
─────────────────
商品清單（可捲動，−/+ 調整數量）
─────────────────  ← 分隔線
[ 使用優惠券 ]
小計
會員折扣　[95折]
優惠券折抵　（更換）
點數折抵　[全折]
─────────────────
會員儲值 N 點（移除）      ← 位置在點數折抵下方
尚需支付　　　　$XXX       ← 34px/900
[現金][信用卡][LINE Pay]
實收現金 + 快捷 100/200/500/1000/剛好
找零
[ 確認結帳 · 扣 N ＋ 收 $X ]
```

**佈局規則**：右欄整體可捲動（`overflow-y:auto`），商品清單 `flex:1 0 auto`（品項少時撐開留白、多時往下延伸不被壓縮），結帳區 `flex-shrink:0` 且上緣有分隔線。

### 代付面板

按鈕：虛線玫瑰框 `1.5px dashed #E3C9D2`、白底、10px 圓角、11px 內距、14px/700、**文字置中**、右側 13px 處 `›` 箭頭（展開旋轉 90°）。

展開列表：粉框容器（`#F0E0E5` 框 + `#FFFBFC` 底），項目含圓形打勾 ＋ 名字 ＋ 金額。已被他人代付者變灰不可點，顯示「已由他人代付」。

**面板展開狀態隨座位切換重置**（有代付關係則保持展開）—— 全域狀態不重置會延續到別人身上。

### 收據（結帳後停留右欄）

```
　　✓ 已完成收費　　      ← 18px/900 置中，打勾圓圈 26px，上下留白 24/22px
─────────────────
消費明細
　品項 ×N              $XXX
─────────────────
小計 / 優惠券折抵 / 會員折扣
應付金額               $XXX  ← 30px/900
─────────────────
收款方式
　點數                   270
　現金                  $591
　- - - - - - - - -
　實收現金             $600
　找零                   $9  ← 玫瑰色 20px/900
[ ＋ 加購新項目 ]
```

**點數歸在「收款方式」而非「折扣」** —— 避免同一筆錢出現兩次，且收款區加總可驗算等於應付金額。

被代付者已結帳時無自己的收據，改顯示卡片：「此位檯費已由 **XXX** 代付／費用含在對方的帳單中，無須另外收款」。

## 三、儲值 Modal

僅選金額（5 快捷 150/500/1000/2000/3000 ＋ 自訂），**不問付款方式**。
自訂金額走中央彈窗輸入。選定後加入本次消費明細一起結帳。
