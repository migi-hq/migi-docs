# 檯費 SKU 商品制

> 這是什麼:把檯費商品化成 SKU 清單,計費改為查表而非寫死。
> 什麼時候讀:改價、加計費模式、對帳、或看 `calc_session_fee_tx` 邏輯時。
> 狀態:**最新版,含新增的「當日暢打」與「配桌可選將數」,尚待併入 開桌結帳流程規格.md**。

## SKU 清單

| SKU | 名稱 | 金額 |
|---|---|---|
| SVC-TBL-DAY | 當日暢打 · 不限將數 | 300 |
| SVC-TBL-M2 | 配桌檯費 · 2 將 | 100 |
| SVC-TBL-M3 | 配桌檯費 · 3 將 | 150 |
| SVC-TBL-MID | 配桌檯費 · 中途加入 | 100 |
| SVC-TBL-P02 | 包桌檯費 · 2 小時內 | 400 |
| SVC-TBL-P05 | 包桌檯費 · 2–5 小時 | 600 |
| SVC-TBL-P24 | 包桌檯費 · 5 小時以上 | 800 |

## 計費對照(依情境)

| 情境 | 帶入 SKU | 金額 |
|---|---|---|
| 開桌選 3 將 | SVC-TBL-M3 | 150 |
| 開桌選 2 將 | SVC-TBL-M2 | 100 |
| 中途加入 | SVC-TBL-MID | 100 |
| 代打補位 | SVC-TBL-MID | 100 |
| 包桌 2 小時 | SVC-TBL-P02 | 400 |
| 包桌 5 小時 | SVC-TBL-P05 | 600 |
| 包桌 24 小時 | SVC-TBL-P24 | 800 |
| 當日暢打 | SVC-TBL-DAY | 300 |

## 與舊規則的差異(相對 開桌結帳流程規格.md)

1. **新增「當日暢打 300」** — 第三種計費模式,不限將數、當日有效。
2. **配桌可選將數** — 原本固定「打滿 3 將 150」,現增加 2 將 100 的選項,開桌時選。
3. **代打補位** 明確歸入 SVC-TBL-MID(100)。

## 已完成

`calc_session_fee_tx` 已更新為使用 SVC-TBL-MID。

## 待確認 / 待辦

- SVC-TBL-* 要放 `products` 表(建議加 `category='table_fee'` 與餐飲區分),或續用 `pricing_tiers` — **未定案**。
- 開桌介面需支援「選將數(2/3)」與「當日暢打」選項(員工後台 + 會員端配桌頁)。
- 收桌邏輯:當日暢打不依將數/時長結算,需獨立分支。
