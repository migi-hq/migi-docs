# MIGI 咪吉麻將 — 系統術語對照表 v0.1

> 目的:台麻民間用語不統一,本表固定全系統(UI、技術文件、員工訓練、簡報)一致用詞。
> 鐵則:**全面台麻用語,不出現日麻用語**(巡、半莊、立直、點棒、副露、ドラ… 一律不用)。

---

## 1. 層級單位(由大到小)

| 層級 | 系統定詞 | DB 欄位 | 說明 | 不要用 |
|---|---|---|---|---|
| 場次 | **將** | games / planned_sets / current_set | 計費與換手單位,一將約 2 小時;自訂單位,台麻民間無固定詞 | 半莊、一鍋 |
| 風圈 | **圈** | (場風) | 東圈/南圈/西圈/北圈,四人各當一次莊為一圈;通用無爭議 | — |
| 單把牌 | **局** | hands | 一把牌:洗牌發牌 → 胡牌或臭莊;通用無爭議。注意連莊使局數與圈非固定對應 | — |
| 一次輪轉 | **輪** | (序號推導) | 四家各摸打一次為一輪;台麻無標準詞,固定用「輪」 | **巡**(日麻) |
| 單一動作 | **手** | paipu_events 序 | 逐手播放的最小單位,例:第 23 手；牌譜查閱用此 | — |

UI 範例:`第 2 將 · 南風圈 · 第 3 局 · 第 6 輪 · 第 23 手`

## 2. 動作與結果用詞

| 系統定詞 | 說明 | 不要用(日麻) |
|---|---|---|
| 胡牌 | 完成一手牌 | 和牌(ホーラ) |
| 自摸 | 自己摸到胡 | — |
| 放槍 / 放炮 | 打出的牌被別人胡 | 放銃 |
| 吃 / 碰 / 槓 | 取用他家牌 | 副露 |
| 聽牌 | 差一張即胡 | — |
| 臭莊 | 流局 | — |
| 詐胡 | 錯誤宣告胡牌 | — |
| 過水 | 可胡不胡、該巡不可再胡同張 | — |
| 起手牌 | 開局發到的牌 | 配牌 |
| 台 / 底 | 計分單位 | 點、翻 |
| 海底撈月 | 摸牌牆最後一張自摸(加台) | — |

座位:**莊家 / 閒家**、**上家 / 下家 / 對家**、東南西北席。

## 3. 營運/系統自訂詞

| 系統定詞 | 說明 |
|---|---|
| 配桌 | 媒合四人成桌 |
| 暫代 | 客人暫離,店員代打數局後換回(成績仍歸原玩家) |
| 接手 | 客人中離,店員打完此局/此將 |
| 換手 | 將邊界的人員替換(補位者打剩餘將數) |
| 受訓店員 | 會打牌、可暫代/接手的店員(兼明星人才池) |
| 點數 | 會員儲值的消費單位(非賭資,不可兌現) |
| 段位 | 會員實力等級 |
| 台數效率 | 胡牌次數與大小的平衡指標 |
| 放槍分析 | 失分情境檢討(對客可稱「失分檢討」) |
| 吃碰槓傾向 | 副露習慣分析(系統不用「副露」一詞) |
| 逐手回放 | 牌局重播(對客可稱「覆盤重播」) |

## 4. 規則集

- 現行:**台 16 張**(tw16)。
- DB 內英文欄位/列舉值(如 `riichi`、`dora_reveal`、`ruleset='jp13'`)**保留供未來擴充,現行不使用、不顯示於任何中文介面**。
- 牌面編碼:萬/筒/索 1–9、東南西北、中發白、花牌;見資料中台文件。
