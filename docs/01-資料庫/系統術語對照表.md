> 目的:台麻民間用語不統一,本表固定全系統(UI、技術文件、員工訓練、簡報)一致用詞。
> 鐵則:**全面台麻用語,不出現日麻用語**(巡、半莊、立直、點棒、副露、ドラ… 一律不用)。

> 🔴 **這份表是名詞的唯一來源。改用詞之前先讀它。**

> —— 還多定義了「手」這一層（我漏掉的那一層），害使用者依一個錯的前提做了決定。

## 1. 層級單位(由大到小)

| 層級 | 系統定詞 | DB 欄位 | 說明 | 不要用 |
|---|---|---|---|---|
| **一次來店** | **場** | table_sessions / session_players | 客人來打的一次,MIGI 賣 **2 將或 3 將**(檯費 SVC-TBL-M2 / M3)。⚠ v0.1 漏了這一層 | 一攤 |
| 場次 | **將** | games / planned_sets / current_set<br>(現行 table_sessions.planned_rounds 是「幾將」) | 計費與換手單位,一將約 2 小時;自訂單位,台麻民間無固定詞 | 半莊、一鍋 |
| 風圈 | **圈** | (場風 hands.round_wind) | 東圈/南圈/西圈/北圈,四人各當一次莊為一圈;通用無爭議 | — |
| 單把牌 | **局** | hands | 一把牌:洗牌發牌 → 胡牌或臭莊;通用無爭議。注意連莊使局數與圈非固定對應 | — |
| 一次輪轉 | **輪** | (序號推導 paipu_events.turn_no) | 四家各摸打一次為一輪;台麻無標準詞,固定用「輪」 | **巡**(日麻) |
| 單一動作 | **手** | paipu_events 序 | 逐手播放的最小單位,例:第 23 手；牌譜查閱用此 | — |

UI 範例:`第 2 將 · 南風圈 · 第 3 局 · 第 6 輪 · 第 23 手`

### 🔴 換算(2026-09-03 逐條查證)——**只有最上面兩層是固定的**

```
8 手      = 1 輪    ⚠ 基準值不是定值
n 輪      = 1 局    ⚠ 不固定（打到胡牌或臭莊才結束）
≥ 4 局    = 1 圈    ⚠ 下限（連莊會拉長）
4 圈      = 1 將    ✅ 固定
2～3 將   = 1 場    ✅ 固定（檯費只有 SVC-TBL-M2 / M3）
```

· **一輪 = 8 手不是 4 手**:`paipu_events.action` 把 `draw` 與 `discard`
  列成**兩個**動作,所以一家摸打一次 = 2 手,四家 = 8 手。
  ⚠ 但它會變動:**吃／碰之後那家不摸牌直接打**(少一手),槓會多出
  `kan_*` ＋ 補摸。
· **一圈 ≥ 4 局不是 = 4 局**:莊家連莊就不換莊。
  📌 `hands` 的唯一鍵是 `(game_id, round_wind, hand_no, renzhuang)`
  —— **`renzhuang` 進了鍵裡**,就是因為同一個 `hand_no` 會因連莊出現多次。
· 一局結束的條件是「胡牌**或臭莊**」,不只胡牌。

🎯 **所以一將 ≥ 16 局,而「一將約 2 小時」是時間估計不是換算。**
  這也正是**計費綁在「將」而不是「局」**的原因 ——
  局數浮動,而客人要能事先知道要付多少。

### 🔴 「手」與「局」不可以互相借用
兩個都是正式定詞，但**指不同的東西**:

```
逐局回放   選哪一把牌來看        （局 = hands 一列）
逐手回放   在那一把裡一步一步走   （手 = paipu_events 一列）← §3 的系統定詞
```
⚠ **已知的違反**:`migi-web/src/pages/profile.jsx` 的「最近亮點」寫
  「胡出**一手**好牌,就會記下你近期最大台的**一手**」—— 那裡指的是**一局**。

### 🎯 每一層對應哪個里程碑(2026-09-03 補)
```
場 ✅ 已有（table_sessions）
將 🟡 只存「幾將」，每一將的結果算完就丟（apply_session_rounds_tx 的註解自己說了）
圈 ⏳ M4（由 hands.round_wind 推導）
局 ⏳ M4 電子計分 —— 台數・自摸・放槍・renzhuang 連莊都在這一層
輪 ⏳ M5 牌譜辨識
手 ⏳ M5 牌譜辨識（paipu_events，有 confidence 欄位）
```
🔴 **所以胡牌率／放槍率／自摸率是 M4 不是 M5** —— 它們只要「誰胡了、誰放槍」，
  那在 `hands` 裡。CLAUDE.md 待辦 33 原本寫成 M5,2026-09-03 已更正。

## 2. 動作與結果用詞

| 系統定詞 | 說明 | 不要用(日麻) |
|---|---|---|
| 胡牌 | 完成一手牌 | 和牌(ホーラ) |
| 自摸 | 自己摸到胡 | — |
| 放槍 / 放炮 | 打出的牌被別人胡 | 放銃 |
| 吃 / 碰 / 槓 | 取用他家牌 | 副露 |
| 聽牌 | 差一張即胡 | — |
| 臭莊 | 流局 | — |
| 詐胡 | 錯誤宣告胡牌 | — |
| 過水 | 可胡不胡、該巡不可再胡同張 | — |
| 起手牌 | 開局發到的牌 | 配牌 |
| 台 / 底 | 計分單位 | 點、翻 |
| 海底撈月 | 摸牌牆最後一張自摸(加台) | — |

座位:**莊家 / 閒家**、**上家 / 下家 / 對家**、東南西北席。

## 3. 營運/系統自訂詞

| 系統定詞 | 說明 |
|---|---|
| 配桌 | 媒合四人成桌 |
| 暫代 | 客人暫離,店員代打數局後換回(成績仍歸原玩家) |
| 接手 | 客人中離,店員打完此局/此將 |
| 換手 | 將邊界的人員替換(補位者打剩餘將數) |
| 受訓店員 | 會打牌、可暫代/接手的店員(兼明星人才池) |
| 點數 | 會員儲值的消費單位(非賭資,不可兌現) |
| 段位 | 會員實力等級 |
| 台數效率 | 胡牌次數與大小的平衡指標 |
| 放槍分析 | 失分情境檢討(對客可稱「失分檢討」) |
| 吃碰槓傾向 | 副露習慣分析(系統不用「副露」一詞) |
| 逐手回放 | 牌局重播(對客可稱「覆盤重播」) |
