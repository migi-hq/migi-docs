# 積分級距規格（純娛樂麻將 → 300/100）

> 這是什麼:MIGI「一桌打多大」的級距定義與用途。
> 什麼時候讀:做配桌分組、成績統計、報表維度、或要新增/調整級距時。

## 定義

積分級距 = 該桌的底/台設定,決定「這桌玩多大」。

| 級距 | 底 | 台 | 計積分 | 計段位 |
|---|---|---|---|---|
| 純娛樂麻將 | — | — | 否 | **是** |
| 10/10 | 10 | 10 | 是 | 是 |
| 30/10 | 30 | 10 | 是 | 是 |
| 50/20 | 50 | 20 | 是 | 是 |
| 60/20 | 60 | 20 | 是 | 是 |
| 100/20 | 100 | 20 | 是 | 是 |
| 100/50 | 100 | 50 | 是 | 是 |
| 200/50 | 200 | 50 | 是 | 是 |
| 300/100 | 300 | 100 | 是 | 是 |

> 「純娛樂麻將」為 2026 定名,取代舊稱「衛生麻將」。全系統一律使用新名。

## 三條鐵則

1. **級距只有兩個用途**:① 配桌分組條件 ② 成績/營運統計維度。
2. **MIGI 點數只收場地費,絕不碰桌上輸贏**(賭博紅線)。級距不影響扣點金額。
3. **純娛樂麻將不計積分,但仍計段位**:只要有消費(開桌)就計順位 → Elo。段位看的是順位/勝負,與玩多大無關。

## 資料驅動

級距存在 `stake_levels` 表,**店家後台可自行新增/停用**(例如加 500/200)。
不寫死在程式,不預設固定清單。

欄位重點:`label`(顯示名)、`base`(底)、`tai`(台)、`is_hygiene`(純娛樂旗標,true 表不計積分)、`sort_order`、`store_id`(null=org 通用,有值=分店專屬)。

## 統計維度用法

級距與「時段」同級,是獨立分析軸:

| 視角 | 看什麼 |
|---|---|
| 店家 | 本月各級距開桌數/熱度 → 決定要多開大注場或純娛樂場 |
| 客人 | 本月各級距場次與勝率 → 我在哪個級距最強(主場) |

原始資料只存「這桌是哪個級距」(`table_sessions.stake_level_id`),報表層自由分組,不預先彙總。

## 配桌分組

不同級距**不可混桌**。配桌條件 = 牌型 + 級距 + 段位 + 時段可打到的時間 + 迴避名單。
