# MIGI 成就系統 200 個｜正式企劃文件 v2.3（10 種 motivation）

> **這是什麼**：200 個成就的正式企劃，分 A~R 共 18 區。每個成就含名稱、客人看到的說明、解鎖條件、結構軸、動機軸，以及可直接上架的 schema 對映欄（code／struct／motivation／visibility）。
> **什麼時候讀**：要實作成就系統、新增成就、或確認某個成就的判定條件時。


> 保留企劃原 5 欄（成就名稱／客人看到的說明／解鎖條件／結構軸／動機軸），右側加上可直接上架的 schema 對映欄。
> 旗艦招牌成就「**咪幾（MIGI）**」為獨立成就，**不佔這 200 的編號**（見既有成就主檔）。
> J 區「局勢轉折」的『正值/負值/排名』= **純娛樂積分／段位順位**，非桌上輸贏金額（守賭博紅線：點數只收場地費）。

## 對映規則

**結構軸 → `struct`（DB 四種）**：特定/組合/收藏套組/對象/地點/觸發/驗證/條件事件/隱藏/稀有/限時/季節/節日/時段/日期 → `specific`；累積分級 → `cumulative`；連續Streak → `streak`；里程碑 → `prestige`。
**動機軸 → `motivation`（10 種）**：完成癖→completion；競爭→competition；社交→social；探索→exploration；收集→collection；榮耀/地位→prestige；**自我表達→expression**（新）；**劇情/話題→story**（新）；消費/回饋→consumption。多重取主要（『/』前第一個）。
**養成規則**：凡 `struct=streak`（連續型）**一律歸 `habit`**（新）——連續登入/月月報到/固定局等的本質是養成回訪習慣，覆蓋原動機軸標籤。
**visibility**：含『隱藏』→ `silhouette`（灰階輪廓）；其餘 `visible`。**收藏套組／里程碑**：trigger 為『解鎖同群 N 個』的 meta 條件，requires_code 留空。

> 10 種 motivation = completion / competition / social / exploration / collection / prestige / consumption / **habit** / **expression** / **story**。
