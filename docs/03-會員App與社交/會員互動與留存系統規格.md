# MIGI 咪吉麻將 — 會員互動與留存系統規格 v0.6

> 目標:用世界級遊戲的留存機制養成黏著,但守住「健康麻將」定位 —— 往**習慣養成、社交、成就感**走,不做賭博式刺激。
> 底層全部建立在既有資產上:點數錢包、牌譜系統、會員資料、訊息機器人、商城。等於把現有資料再榨出多層玩法,非另起爐灶。

---

## 1. 留存引擎總表(五層結構)

> 留存不是平鋪一堆功能,而是分**五層**:個人成長、來店誘因、社交關係、情感歸屬、品牌身分。
> 原十大偏「個人玩法」,本版補強最該強卻最弱的**社交 + 情感**層(契合「女生聚會店」本質)。

| 層 | 引擎 | 機制 | 解決什麼 | 章節 |
|---|---|---|---|---|
| **A 個人成長** | 段位 / 雀神 | 競技排名 + 賽季頭銜 | 長期競爭動力 | 會員分級規格 |
| | 成就 / 徽章 | 牌技/社交/消費里程碑 | 收集、炫耀 | §3 |
| | 小熊養成 | 養成賽季進度 + 裝扮解鎖 | 留存+營收+IP情感 | §7 |
| | 每週任務 | 短期目標刷新 | 這週回訪 | §8 |
| | 每日簽到 | 連續登入遞增獎 | 天天開 App | §6 |
| **B 來店誘因** | 摸彩 | 抽獎 + 保底 | 多消費 | §5 |
| | 事件 | 限時活動 | 今天就來(填空桌) | §4 |
| | AI 動態(長線) | 個人化挑戰/推播 | 精準留存 | §10 |
| **C 社交關係** | 推薦揪團 | 雙向獎勵 + 湊咖 | 老客帶新客 | §9.5 |
| | **好友 / 牌咖** | 加好友、揪固定咖開桌 | **回流真引擎(為那群人來)** | §13 |
| | **戰隊 / 姊妹團** | 組隊、團體賽、團排 | 個人黏著→整群來 | §14 |
| | **送禮** | 送飲品/裝扮給朋友 | 社交貨幣 | §15 |
| **D 情感歸屬** | 名人堂 + 雀神俱樂部 | 持續尊榮(非畢業) | 頂端不流失 | §9 |
| | **生日 / 紀念日** | 生日禮、入會週年 | 被記得、被在乎 | §16 |
| | **年度回顧** | 個人數據總結(可分享) | 自發病毒分享 | §17 |
| **E 品牌身分** | **公益連結** | 消費回饋、長者陪伴公益場 | 身分認同、對抗賭博污名 | §18 |

**飛輪:** 事件把人拉來 → 消費累積摸彩/任務 → 打牌解鎖成就/養大熊 → 揪好友姊妹團一起來 → 年度回顧自發分享 → 吸引新朋友 → 再被拉來。

## 2. 健康定位的克制原則(凌駕一切)

- 客群含中高齡、且系統碰錢(點數儲值)→ 摸彩/小熊養成的「課金感」必須克制。
- 留存往「習慣、社交、成就感」走,**不做賭博式抽獎刺激、不誘導非理性消費**。
- 摸彩須有**保底與透明機率**;不設「越輸越想加碼」的機制。
- 「健康」是品牌定位,守住此線 → 留存系統是護城河;踩線 → 傷品牌+監管風險。

## 3. 成就系統與獎勵設計

### 3.1 成就分三種深度
- **消費/到店成就**(任何店都有):首儲、連續來店、消費里程碑、揪團達人(帶 N 人入會)。
- **社交成就**(扣聚會定位):固定咖(跟同群打 N 場)、閨蜜認證(跟好友同桌 N 次)、破冰王(跟 N 個新朋友同桌)。
- **牌技成就**(靠牌譜,別人做不到,全自動偵測):特定牌型(大三元/清一色…)、零放槍之夜、逆轉勝、海底撈月、段位里程碑。

### 3.2 獎勵四層(核心原則:獎勵要「買不到」或「炫得出去」,別只給折扣)

| 層 | 獎勵 | 成本 | 用在 |
|---|---|---|---|
| ① 榮譽型 | 專屬徽章/稱號、成就牆排名、限定頭像框/小熊裝扮 | 零 | **主力**,大量用 |
| ② 體驗型 | 配桌優先權、包廂體驗券、賽事報名優先/免費、保留座 | 低 | 社交/中階成就 |
| ③ 限定解鎖 | 成就才能**購買**的限定/編號商品(解鎖購買權,非免費送) | 中 | 牌技/稀有成就 |
| ④ 點數餐飲 | 少量點數、招待飲品/甜點、生日同名甜點 | 直接 | **最克制**,僅少數里程碑 |

### 3.3 成就 × 獎勵搭配邏輯

| 成就類型 | 給什麼 | 為什麼 |
|---|---|---|
| 日常小成就 | 榮譽徽章 + 少量點數 | 量大,用便宜的 |
| 社交成就 | 配桌優先權 + 徽章 | 鼓勵帶人,給體驗 |
| 牌技成就 | 稀有徽章 + 限定商品解鎖 | 難達成,給炫耀+收藏 |
| 頂級成就 | 稱號 + 限量編號品 + 包廂 | 萬中選一,給最稀缺的 |

### 3.4 三避坑
1. 別讓獎勵全是折扣 → 會把客人訓練成「為省錢才打牌」。
2. 稀有成就的獎勵要真的稀有 → 難度與獎勵匹配,否則沒人珍惜。
3. 善用「解鎖購買權」而非「免費送」→ 既給榮譽又賺營收,對點數經濟最健康。

## 4. 事件系統
- 常態週期:週二閨蜜日(三人同行優惠)、週四養生場(無咖啡因買一送一)、每月雀神週。
- 節慶限定:母親節、過年、週年慶。賽季事件:每季雀神收尾戰。
- 訊息機器人推播填空桌時段(「今晚閨蜜日,揪團現省」)。

## 5. 摸彩系統
- 消費抽(每消費 X 點得一抽)/儲值加碼抽 → 推高客單與現金流。
- 扭蛋式 App 動畫(粉色扭蛋),抽小熊周邊/飲品券/桌時折抵/限定品 → 過程即打卡點。
- **保底**:抽 N 次必中;**透明機率**公開。季度頭獎(限量聯名尺/雀神同款)製造話題。

## 6. 每日簽到(連續登入)
- 每天開 LINE 簽到領點數/飲品券,連續遞增,7 天大獎,斷一天重置。
- 價值:**沒來店也讓人天天開 App**,維持品牌存在感+看到當日活動;對規律型客群尤其有效。

## 7. 小熊養成(原「戰令 Battle Pass」概念,改養成系命名/定案)
> 把戰令的「賽季進度+雙軌獎勵」包裝成「養一隻屬於自己的小熊」。情感黏著遠強於集點冊:玩家捨不得中斷一隻養了多日的熊。吉祥物從裝飾升級為夥伴。
- **養成主體**:每位會員有一隻命名小熊(可改名),有等級 Lv、心情、裝扮。
- **成長階段**(對齊段位,天然合體):幼幼熊 → 見習熊 → 好手熊 → 高手熊 → 大師熊。
- **餵養動作 = 消費/打牌/社交**:打一場 +20、點甜點 +10、揪閨蜜 +30(數值示意)→ 累積成長值升 Lv。
- **雙軌獎勵**:成長禮 🎀(免費,人人有)/ 蜜糖禮 🍯(升級解鎖,付費軌)。解鎖內容多為**小熊裝扮**(蝴蝶結、洋裝、彩妝)+ 周邊/飲品/商城折抵/體驗券 → 獎勵直接「穿在熊身上」,養成感最強。
- 對齊雀神賽季(每季 ~3 個月)結算;免費軌+付費軌 = 會自賺錢的留存系統,與賽季制合體。
- **美術需求**:小熊各成長階段 + 各裝扮素材(可複用至周邊、貼圖、店裝)。

## 8. 每週任務
- 每週刷新:「打 3 場」「跟新朋友同桌 1 次」「試三人麻將」→ 完成領獎,並餵小熊養成進度。
- 與成就區別:成就=永久里程碑;任務=每週短期目標,給回訪理由。

## 8.5 成就 vs 小熊養成:界線與互補(避免重複)

> 兩者都在記錄「變強」,但機制不同,不重疊——關鍵是**吃不同的東西、給不同的獎**。

| | 小熊養成 | 成就 |
|---|---|---|
| 性質 | 連續累積(像經驗值) | 離散里程碑(像獎盃) |
| 觸發 | 做任何事都 + 進度 | 達成**特定條件**才解鎖 |
| 時間 | 賽季重置 | 永久保留 |
| 獎勵 | **小熊裝扮**、賽季限定(穿在熊身上) | **徽章/稱號/限定購買權**(掛名字旁) |
| 心理 | 「我每天都在養」 | 「我做到了特別的事」 |
| 比喻 | 健身累積時數 | 破紀錄紀念徽章 |

**兩條不打架的鐵則:**
1. **獎勵分工**:養成只給「裝扮+賽季限定」(可愛、陪伴);成就只給「徽章/稱號/解鎖購買權」(榮譽、炫耀)。同一樣獎品不可兩邊都送。
2. **觸發可共用、獎勵不共用**:同一個行為(如打 10 場)可同時餵養成進度、也推成就進度,正常;但拿到的獎不同樣。

**讓兩者互相加分的串接**:達成稀有成就時,除了給徽章,**額外一次灌一大筆小熊成長值** → 「我打出大三元,我的熊也跟著大跳級」。平常慢慢養、壯舉時暴衝,兩系統互補不搶戲。

## 9. 名人堂 + 雀神俱樂部(頂端玩家的「持續尊榮」,取代會趕客的「畢業/引退」機制)

> 修正:電玩 Prestige 讓玩家「畢業離場」對實體店是反效果——目標是讓人一直回來。
> 真問題是「頂端玩家爬到頂後沒新目標而流失」,解法是**給源源不絕的新目標 + 持續尊榮**,而非出口。

- **大師熊不是終點,是無限賽季榜的起點**:到頂後進入每季重新爭奪雀神的循環(雀神一季一位、會被搶),頂端玩家永遠有「這季當不當得上/守不守得住」的理由回來。
- **歷代雀神牆(越留越光榮)**:當過雀神名字永久留店;但人**繼續打**,每多拿一次多一顆星/多一年份 —— 累積榮譽,不是一次性離場。
- **長期紀錄追不完**:衛冕雀神、年度總積分王、十次雀神俱樂部…給頂端玩家永遠追不完的長線目標。
- **雀神俱樂部(身分綁在場)**:當過雀神/到頂者組成常駐尊榮圈,享專屬包廂、專屬聚會、賽事表演賽邀請;**前提是仍為活躍會員** → 榮譽跟著「持續在場」走。
- **轉明星身分(接 IP 線)**:頂級玩家可受邀當表演賽嘉賓、教學直播主、新人導師 → 從「玩家」變「店裡名人」,更離不開。
- 一句話:頂端玩家「**越爬越尊榮、越不想走**」,與「畢業」完全相反。

## 9.5 會員推薦獎勵(Referral · 成長引擎)

> 麻將是「四人成局」的生意,老客帶新客不只是行銷,根本是**幫店裡湊咖**。閨蜜揪閨蜜 = MIGI 最強獲客引擎。
> 核心原則:**雙向獎勵 + 真消費才發(防刷)+ 綁湊咖痛點**。

### 推薦階梯(獎勵分階解鎖,非註冊即發)
| 階段 | 觸發 | 新客拿 | 推薦人拿 |
|---|---|---|---|
| 註冊 | 新客綁定推薦碼 | 入會禮(招待飲品) | — |
| 首次消費 | 新客第一次到店消費 | — | 推薦獎(少量點數+徽章進度) |
| 變常客 | 新客一個月來 3 次 | 老客回饋(再一杯) | 養成獎(配桌優先權) |
| 揪滿一桌 | 一次帶 3 人成桌 | 全桌折扣 | 揪團達人徽章 + 大獎 |

### 設計要點
- **雙向都給**:只給單邊會失效(只給老客→新客沒動力;只給新客→老客懶得推)。
- **分階解鎖防刷**:獎勵綁「真實消費行為」,假帳號/人頭註冊拿不到主獎。
- **獎勵組合**(沿用「買不到/炫得出去」邏輯):體驗型(配桌優先權/包廂體驗)+ 少量點數 + 成就徽章(揪團達人);**不影響段位**(段位只看牌技,保持競技純粹)。
- **湊咖獎(MIGI 獨門)**:「揪滿一桌」一次帶 3 人成桌加碼大獎(直接幫店裡填滿一桌,價值最高);帶來的朋友變固定咖 → 持續回饋推薦人。

### 追蹤機制
- 每會員有專屬推薦碼/連結(LINE 一鍵分享)。
- 新客註冊填碼/點連結 → 系統自動綁定 `members.referred_by`。
- 後續消費自動觸發雙向獎勵發放。

### 避坑
1. 獎勵別太重 → 太大會吸引「為賺獎勵而推薦」的低質客;適中+真消費才給即可過濾。
2. 設月上限 → 防止當副業刷。
3. 新客首次體驗優先 → 推薦來的人標記為「VIP 介紹」,店員多關照,避免砸老客招牌。

## 10. AI 動態活動(長線)
- 牌譜+消費資料 → 個人化任務與推播(放槍高者推防守挑戰;流失風險者推召回優惠)。
- 不急於初期做;先把資料存好,資料中台成熟後解鎖。

## 13. 好友 / 牌咖系統(社交層 · 回流真引擎)

> 麻將最強的回流動力是「**那群人**」,不是系統。人是為了固定牌咖回來的。
- 加好友、看誰在線/在店、一鍵揪固定咖開桌。
- 「我的牌咖團」:常一起打的人自動成團,顯示彼此段位、約打紀錄。
- 配桌可選「優先跟好友同桌」(接配桌引擎 prefer 名單)。
- 好友揪約 → 直接觸發配桌請求 + 訊息機器人通知對方。

## 14. 戰隊 / 姊妹團(社交層 · 個人黏著→整群來)

> 把個人留存升級成「一整群人一起來」。閨蜜團 = 最強的揪團單位。
- 組姊妹團(3–8 人),有團名、團徽(小熊團徽可自訂)。
- 團體賽 / 團體積分榜:全店姊妹團排名,季度團體冠軍。
- 團體任務:「本週全團合計打 20 場」→ 達標全團領獎,製造互相揪約壓力。
- 團體養成:小熊可組「熊熊家族」合照。

## 15. 送禮系統(社交層 · 社交貨幣)

> 讓「在乎」可以被表達。送禮是女性社群最自然的互動。
- 送朋友:一杯飲品券、一個小熊裝扮、點數小紅包(節慶)。
- 生日自動提醒「要不要送 ___ 一杯?」。
- 收禮有通知+感謝回禮機制,形成互動循環。
- 防濫用:送禮走點數、有金額/次數上限,不可變現。

## 16. 生日 / 紀念日(情感層 · 被記得)

> 中高齡客群最吃「被記得、被在乎」。零成本、高情感回報。
- 生日:生日禮(同名甜點/點數/限定裝扮)、生日當天配桌小驚喜。
- 入會週年:「陪妳打牌一年了」+ 週年回顧 + 紀念徽章。
- 重要里程碑:第 100 場、第一次胡大牌的「那一天」紀念。
- 訊息機器人主動推播,不需客人記得。

## 17. 年度回顧(情感層 · 自發病毒分享)

> 仿 Spotify Wrapped:把個人數據包成「值得炫耀的回顧」,客人自己會分享。零廣告成本的裂變。
- 年度/季度總結:今年打了 N 場、最佳牌型、最高連勝、最常一起打的牌咖 Top3、養成的熊成長軌跡、最愛點的甜點。
- 做成精美可分享圖卡(MIGI 品牌視覺),一鍵發 IG/限動。
- 季度小回顧 + 年度大回顧;年末是天然行銷檔期。

## 18. 公益連結(品牌層 · 身分認同 + 對抗污名)

> 「健康麻將」要對抗「麻將=賭博」的社會污名,公益是最強武器,也給客人「我來這裡是好事」的身分認同。
- 消費部分回饋指定公益(長者照護、婦幼)。
- **長者陪伴公益場**:會員可當志工陪長輩打牌(防失智益智活動),時數換榮譽徽章/點數。
- 與在地社福、里長、日照中心合作 → 媒體話題 + 社會正當性。
- 「健康麻將」從口號變成可驗證的社會貢獻;對招商、加盟、政府關係都加分。

## 11. 資料表(新增,銜接現有核心)

```sql
create table achievements (          -- 成就定義
  code text primary key, name text, category text,  -- consume/social/skill
  reward_type text, reward_ref text, rarity text);
create table member_achievements (   -- 會員達成記錄
```

## 12. 分波上線表(取代籠統里程碑)

> 校準原則(來自實務):**麻將客人 99% 的誘因是「有牌打」,留存引擎是輔助。**
> 所以:十六引擎一個不砍、藍圖完整保留,但**上線分波、資料先行**——功能可以晚上線,資料累積不能晚開始。

| 波次 | 引擎 | 理由 |
|---|---|---|
| **Day 1(與配桌同步)** | 好友/牌咖、推薦揪團 | 這兩個**就是成桌率本體**(固定咖一鍵開桌、三缺一推播、揪人),非附加品,升格至配桌核心 |
| **開店即有(零邊際成本)** | 每日簽到、生日/紀念日、牌技自動徽章、事件推播 | 機器人一條規則/牌譜副產品,幾乎不花工 |
| **首批會員穩定後** | 小熊養成、每週任務、摸彩、送禮 | 有人了,玩法才有意義 |
| **賽季制啟動後** | 段位賽季、名人堂/雀神俱樂部、姊妹團團體賽 | 跟著賽季節奏走 |
| **資料夠厚後** | 年度回顧、AI 動態 | 沒資料做不出來;回顧需至少一季數據 |
| **品牌期** | 公益連結 | 配合公關與在地合作節奏 |
| **Day 1 必做** | **全部十六引擎的資料表** | 建表近零成本;簽到/消費/對局/好友關係**從第一天開始累積**,半年後要做年度回顧時資料已在 |

**鐵則:資料表 Day 1 全建、功能分波上線、好友牌咖不算留存引擎算成桌率。**
