# MIGI 咪吉麻將 — 兩種牌咖關係與護城河戰略 v1.0

> 中心思想:**MIGI 不是「比較高級的麻將館」(場地生意),而是「關係製造機」——製造並擁有牌咖關係網絡,場地只是載體。**
> 把「配桌」從一個營運功能,重新定義成 MIGI 的核心護城河引擎。
> 本文固化創辦人實務洞察:外部揪團互加 vs 配桌陌生人互加,本質完全不同。

---

## 1. 兩種牌咖關係的本質差異

看起來都是「互加牌咖」,本質完全不同:

| | 外部揪團互加 | 配桌陌生人互加 |
|---|---|---|
| 關係來源 | 本來就認識(朋友/同事/脆IG約的) | **MIGI 無中生有創造** |
| 關係強度起點 | 本來就強 | 從零創造 |
| 對 MIGI 依賴度 | 低(沒 MIGI 也存在) | **高(離開 MIGI 就散)** |
| MIGI 的角色 | 保存器 | **媒人/創造者** |
| 護城河價值 | 弱(鞏固既有) | **強(獨佔新關係)** |

**關鍵:配桌陌生人關係比外部揪團珍貴一百倍。** 外部揪團的關係不靠 MIGI 也存在,你只是場地;配桌陌生人的關係完全依賴 MIGI 而生——這群人的牌咖網絡長在你的平台上,離開 MIGI 就散。

---

## 2. 為什麼「配桌陌生人關係」是抄不走的護城河

競爭者可以抄裝潢、抄 App、抄定價,但**抄不走「在 MIGI 認識的這群牌友」**。

- 這群人的關係長在 MIGI 平台上 = 網路效應
- 每多一組陌生人變固定牌咖,護城河就深一分
- **會複利成長**:關係越多 → 新人越容易配到合拍的 → 關係又更多 → 飛輪
- 競爭者就算開一模一樣的店,也複製不了「在 MIGI 認識的這群人」

→ 護城河不在場地,在「MIGI 幫陌生人湊成牌咖、這關係只存在於 MIGI」。

---

## 3. 戰略推論:刻意鼓勵「單人來店」(創辦人實務驗證)

**既然配桌陌生人關係才是護城河,MIGI 應該刻意鼓勵單人來店。**

理由:
- 單人來店的人,**100% 要靠 MIGI 配桌、100% 在創造新關係**(護城河貢獻最大)
- 自帶整團雖好做,但對護城河貢獻低(鞏固既有關係)
- **傳統麻將館:一個人去打不了;MIGI:讓「單人成行」變可能** —— 這既是別人做不到的差異,又是護城河最大來源

**戰略指令**:讓「一個人也敢來、來了一定有牌打、還能認識新牌友」成為 MIGI 核心賣點。單人客正是最該珍惜的護城河貢獻者。

(實務印證:創辦人經驗——外部揪團客人很有機會互加牌咖;配桌陌生客人也有機會互加牌咖。後者才是 MIGI 獨有、別人給不了的。)

---

## 4. 兩種關係的差異化經營

### 外部揪團(已有關係)→「收編 + 裂變」
- 報到時「你們是一起的嗎?」→ 綁定牌咖(留住關係資料)
- 整團獎勵:升級「戰隊/姊妹團」,團體優惠、團體賽
- 鼓勵裂變:每人各自再揪自己的朋友 → 網絡細胞分裂
- 提供可貼到脆/IG 的揪團素材(外部社群變免費行銷管道,帶 MIGI 品牌導流回店)

### 配桌陌生人(新關係)→「媒合 + 促成 + 重逢」(重點)
- **a. 配得好**:配桌不只看「有沒有人」,要看合不合得來(段位/年齡/風格)→ 越合拍越可能互加
- **b. 臨門一腳**:收桌時系統推「今天同桌的小美打得不錯?加為牌咖,下次一鍵揪」→ 降低互加摩擦 + 互加獎勵
- **c. 製造重逢**:互加後系統「妳的牌咖小美今晚有來,要不要一起?」→ 把新關係變固定習慣 → 鎖客

---

## 5. 配桌引擎:從「湊人」升級為「媒合」

把洞察轉成系統需求——配桌演算法不能只滿足「找到四個人」,要做到「找到四個**合得來**的人」。

**合拍度評分維度**:
- 段位相近(打起來舒服、不會輾壓)
- 年齡層相近
- 打牌風格相近(輕鬆打 vs 認真打)
- 過去同桌愉快度(打完有沒有互加、有沒有再一起)

**配得越合拍 → 打完越想互加 → 創造的關係越多越穩** = 讓護城河變深的技術槓桿。
(連動《配桌引擎技術設計》:約束求解 + 合拍度評分。)

## 6. 對標與驗證

- **Strava(運動社交)**:一起運動→軌跡重疊→系統建議互相 follow/按讚→持續回來。與 MIGI「一起打牌→綁牌咖→下次揪」是同一飛輪。Strava 靠此做到極強黏著,是護城河典範,**最值得研究**。
- **Facebook 地理交友建議**:同處一空間→推斷關係→建議互加。MIGI 用「同桌打牌 2 小時」這個更強訊號,推斷更準。
- **新一代線下優先社交 App**(Offline、Small.World 等):印證「線下相聚→收編成數位關係」是當前趨勢。

**MIGI 場景優於一般交友 App**:同桌 2 小時是極強關係訊號(vs GPS 鄰近的弱訊號);打牌互動深、自然重複、可直接變現(桌費/餐飲)。

---

## 7. 隱私紅線(必守)

Facebook「同地點就推薦」常被批侵犯隱私。MIGI 必須避開:
- **必須「同桌打過牌 + 雙方同意」才綁定**(系統問「你們是一起的嗎?」就是同意機制)
- 不可變成「只要來過店就互相被推薦」
- 手牌/個資即時只存不顯示(見牌譜系統隱私原則)
