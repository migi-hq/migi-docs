## 建議閱讀順序（新接手者）

## 關於程式碼

前端程式碼**不放在這個交付包裡**，因為：
GitHub repo（migi-hq/migi-web）才是唯一真實來源，而 repo 已有本對話之後的新改動
（固定局、黑名單前端、底注擴充等）。放進來的舊版 jsx 反而會造成版本漂移——
那正是這個專案反覆吃虧的地方。

**規矩：任何人（含 AI）改程式前，先確認手上的是最新 repo 版本。**
