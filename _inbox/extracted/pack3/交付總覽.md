# MIGI M2 交付總覽

> 這是什麼：本批交付的檔案索引與擺放位置建議。
> 什麼時候讀：拿到這批檔案時先看這份，決定各檔要放哪裡。

## 擺放建議

```
migi-pos/
  src/OpenSetupPage.jsx          ← pos-src/OpenSetupPage.jsx（新增）
  src/OpenCheckoutPage.jsx       ← pos-src/OpenCheckoutPage.jsx（覆蓋）
  src/App.jsx                    ← pos-src/App.jsx（覆蓋）
  src/lib/api.js                 ← pos-src/lib/api.js（覆蓋）

migi-web/
  src/lib/analytics.js           ← app-src/lib/analytics.js（覆蓋）
  src/pages/wallet.jsx           ← app-src/pages/wallet.jsx（覆蓋）
  src/pages/match.jsx            ← app-src/pages/match.jsx（覆蓋）

docs/                            ← docs/ 底下的 .md 與設計基準 .html
sql/applied/                     ← 已在 Supabase 執行過
sql/pending/                     ← 尚未執行
```

**程式碼檔名維持英文** —— 那些名稱要與 repo 內的 import 路徑一致，改中文會導致建置失敗。
