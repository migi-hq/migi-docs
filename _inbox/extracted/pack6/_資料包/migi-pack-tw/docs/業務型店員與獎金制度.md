# MIGI 麻將連鎖 — 業務型店員與獎金制度 v1.1

> 創辦人實務經驗:**店員很重要、獎金很重要**。店員不是服務員,是「會打牌的業務」;沒有獎金設計,「業務型店員」只是口號。
> 上位依據:《戰略備忘》隱憂三——成桌率是核心產品;店員是「把桌湊成」的人肉介面。

---

## 1. 角色定義:像業務,不像服務員

| | 傳統麻將館店員 | MIGI 業務型店員 |
|---|---|---|
| 角色 | 服務員(泡茶、收桌、結帳) | 業務(把桌湊成、經營客人) |
| 姿態 | 被動等客人 | 主動經營名單 |
| KPI | 把茶泡好 | 把桌湊成、客人回訪 |
| 成本性質 | 成本中心 | 收入中心 |
| 類比 | — | 保險業務 / 健身教練 / 酒店幹部 |

**系統是雷達,店員是飛彈**:配桌引擎找出三缺一、CRM 標記流失風險,但對中高齡客群,最終轉化靠「人」——店員去把人叫來、去噓寒問暖。系統推播是冷的,店員一通「姐~今天差妳一咖」是熱的。

### 店員四個主動職能
1. **養牌咖池**(像業務養客戶名單):自己的客人、加 LINE、久沒來主動關心。
2. **現場撮合**(像酒店幹部排桌):看誰合得來、幫新客破冰入桌、當桌上化學反應的潤滑劑。
3. **自帶網絡**(招募即獲客):徵「會打牌、有牌友圈」的人 = 買進一個牌咖網絡。
4. **代打補位**(最後保桌手段):冷啟動期保證開桌靠她們。

## 2. 獎金制度(制度核心)

**原則:獎金掛「客人也開心的指標」,不掛「會逼出推銷的指標」。**

| 獎金項 | 觸發 | 逼出的(好)行為 |
|---|---|---|
| **① 成桌獎金(主力)** | 每促成一桌(叫來/撮合/代打救活),系統記錄「促成店員」自動歸因 | 拼成桌 = 客人有牌打 = 核心產品交付 |
| **② 名下客人回訪獎金** | 名下會員月活躍/回訪達標 | 關心客人、噓寒問暖 |
| **③ 帶新獎金** | 帶進的新會員首次消費後發,變常客再補養成獎 | 自帶網絡、拉新 |
| **④ 代打津貼** | 代打補位按場次給 | 不排斥救場(代打是工作不是福利,要算錢) |

### 雙重歸因 + 雙重獎金(v1.1 細化,兩店員可同時各拿)

一個客人來打牌,可能同時養活兩個店員的業績——**兩種不同貢獻,各自獎勵**:

| 獎金 | 獎勵的貢獻 | 歸因 | 金額(可後台改) | 發放條件 |
|---|---|---|---|---|
| **配桌獎金** | 把這桌湊成(客人今天有牌打) | 促成店員 | **50 元/桌** | 店員人工配才發;系統自動配→進全店池(不勞不獲) |
| **綁定客人獎金** | 長期養這個客人 | 主責店員 | **10 元/人/次** | 名下客人每次有效消費(收桌+消費≥100)即抽 |

**情境**:阿美配的桌、小婷是阿珍的客人 → 阿美拿配桌 50、阿珍拿綁定 10,兩人各拿各的。
**一桌上限** = 50 + 4人×10 = **90 元**(視客人綁定狀況浮動,未綁店員的人不發那 10)。

**設計用意**:
- 配桌獎金鼓勵「主動湊桌」(連不是自己的客人也願意湊)→ 提升成桌率
- 綁定獎金鼓勵「長期養客人」(客人來越多次抽越多,像續期佣金)→ 提升回訪
- 系統配進公池 → 自然鼓勵店員搶在系統前面成桌(系統是雷達、店員是飛彈)
- 防刷:綁定獎金需實際完成收桌+消費達門檻,避免刷單

**成本性質**:這是變動成本(成桌越多、客人來越多才發越多),屬良性成長——多付的獎金代表生意也成長了。已納入損益模型變動成本項。

### 刻意不掛:儲值金額 🚫
掛了會出現「姐~再儲一萬啦」的推銷現場,毀掉「安心」定位。**儲值是客人被服務好之後的自然結果,不是店員業績目標。業務的是關係,不是推銷。**

## 3. 實務關鍵設計

- **獎金即時可見**:店員後台首頁放「本月:促成 XX 桌 · 獎金累計 $XXXX」——業務動力來自看得到數字在跳;月底才結算激勵減半。
- **底薪獎金比例**:約「底薪 6–7 成、獎金 3–4 成」起步。底薪保生活(否則請不到人),獎金拉差距(王牌店員月收明顯高於同業 → 留得住戰將、吸引對的人應徵)。
- **防作弊**:成桌歸因綁實際開桌時數+消費紀錄,系統層擋掉灌水(假 head count、空桌假開)。
- **團隊與個人平衡**:全店成桌率達標再加一層全店獎金 → 避免店員搶客/藏客。客人是「店」的資產,店員是服務者+受益者。

---

## 4. 徵才畫像(與傳統餐飲完全不同)

- 找的不是餐飲服務生,是「**會打牌的里長伯 / 保險阿姨型人格**」:自來熟、記得住人、愛張羅、有人脈圈。
- 年齡可偏大(40–50 歲大姐是此客群的天然信任對象)。
- 硬條件:會打台麻、有自己的牌友圈。

---

## 5. 系統需求(連動開發)

- **店員後台「我的客人」視圖**:名下會員、誰多久沒來、誰生日快到、今天哪桌缺人、本月業績與獎金即時數字。像給業務用的 CRM。
- **促成店員歸因**:每桌記錄促成者;每會員綁服務店員;資料表加欄位支援獎金自動結算。
- (連動《整合系統開發藍圖》員工後台、《牌譜成績資料中台》對局記錄、CRM 模組。)

---

## 6. 與加盟擴張線銜接

**最強店員 = 店長 / 加盟主的最佳候選**:她有客人、懂運營、被獎金驗證過。
業務型店員制度不只解決成桌率,還是**加盟主的人才水庫**——接平台化四通路的加盟線。
