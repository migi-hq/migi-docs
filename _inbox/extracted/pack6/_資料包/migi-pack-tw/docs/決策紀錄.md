## 品牌與定位

- 品牌 **MIGI 麻將連鎖**,CIS:蜜桃粉 #FAD6DC、櫻花粉、淺灰、奶茶 #DBC3B5、白;小熊吉祥物;精品粉不是少女粉。
- 定位:「乾淨、安心、有質感的麻將空間,女生也愛來」。男 8 女 2,女性友善是吸客鉤子,**但女性是真核心客(紅線),不是誘餌**。
- 核心產品 = **成桌率**(99% 動機是「有牌打」)。
- 護城河四層:① 數據累積 ② 網路效應(人鎖人)③ 品牌信任 ④ 平台化。

## 分級雙軌

- **會員等級**(消費累積,不含儲值):珍珠奶茶 → 焦糖布丁 → 提拉米蘇。門檻 0 / 10k / 50k(待定)。
- **段位**(打牌 Elo,小熊):銅牌熊 → 銀牌熊 → 金牌熊 → 白金熊 → 鑽石熊 → 大師熊,各 I–IV 小級,可掉段,起始約 1000。大師熊需賽事認證。
- 雀神熊 = 賽季頭銜(一季一位)+ 名人堂,另設女子組平行頭銜。
- UI 兩者並列顯示,如「焦糖布丁 · 金牌熊 II」。
- **會員端 App 禁用數字段位(三段/四段),一律用小熊**。

## 計費與金流

- 配桌按人頭、包桌按時間階梯(見 table-fee-sku-catalog.md 為最新)。
- **開桌即扣**,不等收桌 — 佔位就付,保護成桌率。
- **現金一律先轉點數**;點數只收場地費,**絕不碰桌上輸贏**(賭博紅線)。
- 收桌觸發三項更新:消費累積 / 段位 Elo / 店員業績。

## 開桌方式

- 櫃台報到 + **雙軌開桌**(滿四自動 / 店員手動例外)。
- 身分雙軌:LIFF 掃會員碼 / 報手機 / 店員代開(line_user_id 留空)。
- 識別用 **LIFF 掃會員碼**,不做實體卡、不做人臉。
- 員工後台採**購物車式開桌**:選空桌 → 連續掃會員進明細 → 選積分級距 → 合計 → 一鍵開桌結帳;餘額不足擋下。

## 技術棧

- 前端 Vite + React 純前端 SPA → Cloudflare Pages。
- 後端 Supabase(DB + Edge Functions + Storage + Auth)。
- 程式碼**只放 GitHub 一處**,Cloudflare 自動從 GitHub 抓取部署(非兩邊各存一份)。
- 會員通路走 LINE / LIFF。
- Supabase 一律 **Dashboard 操作**,不用 CLI。
- 資料:會員資料存 Database,檔案(照片)存 Storage,網址存回 Database 欄位(如 `avatar_url`)。

## 帳號與網域啟動順序(雞生蛋解法)

1. 開專用 Gmail(如 migi.founder@gmail.com)當過渡信箱。
2. 用它註冊網域商(Gandi)、買下網域。
3. 開 `admin@` / `info@` 等公司信箱。
4. **回頭把網域商帳號聯絡信箱改成 `admin@`**(轉正)。
5. 之後所有平台一律用 `admin@` 註冊(綁職能不綁人,開 2FA)。
6. 過渡 Gmail 留作緊急復原。

> 個人信箱只是啟動鑰匙,用完功成身退;鑰匙圈最後落在 admin@。
> migi.com / migi.com.tw 已被佔用,改用 migi.tw / migi.app。

## 空間與成本(15 坪首店)

- 15 坪狹長型(面寬 4.5m × 進深 11m)可放 **6 桌**自動麻將桌;主走道 0.9m。
- 動線:入口 → 櫃台報到 → 主走道入座 → 最裡茶水/廁所。
- 開辦成本約 **116–191 萬**(建議抓 130–180 萬);每月固定成本約 22–25 萬。
- 自動麻將桌一台 1.5–2 萬(6 台 9–12 萬);品牌/系統/開辦雜支壓在 5 萬內(系統自建、行銷自己來)。
- 總資金建議準備 220–330 萬(含 3–6 個月週轉金)。
- **不能省的**:空調/除菸/軟裝 — 這是女性友善的命脈。
