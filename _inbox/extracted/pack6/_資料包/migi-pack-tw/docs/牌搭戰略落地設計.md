# 牌咖戰略落地設計 v1.0

> 把《牌咖關係與護城河戰略》從「為什麼」推進到「怎麼做」。
> 核心:MIGI 是「關係製造機」,配桌不是湊人,是媒合對的人 → 每次成功媒合都在平台上多綁一條人際關係。
> 本文含:機制設計、前端落點、後端觸發、演算法需求、新增項目清單。可交工程師。
> 語言:繁體中文、台麻用語。對應簡報第 8 頁《成桌責任光譜》③④。

---

## 總綱:兩條主線

| 主線 | 客流來源 | 策略 | 護城河角色 |
|---|---|---|---|
| A. 外部揪團(已有關係) | 客人自帶的私人牌局 | 收編 + 裂變 | 把場外關係搬進系統,並讓它自我複製 |
| B. 配桌陌生人(新關係) | 系統/店員媒合 | 媒合 + 促成 + 重逢 | 無中生有創造關係,變固定習慣鎖客 |

A 是「把現成的關係網收進來」,B 是「製造原本不存在的關係」。
B 是護城河最深處,也是本文重點。

## 一、外部揪團 →「收編 + 裂變」

> 心法:客人的私人牌局是免費的現成關係網。重點不是賺這桌錢,是把整個網搬進系統 + 讓它分裂複製。

### ① 報到綁定(收編關係資料)
- **機制**:報到/開桌時確認「你們是一起的嗎?」→ 一勾選,同桌互相綁成牌咖。
- **意義**:把「場外關係」變成「場內資料」——他們本來就是朋友,但這份關係現在記在 MIGI 系統裡,成為日後媒合、重逢、裂變的基礎。
- **前端落點**:
  - 員工後台:購物車式開桌時,加一個「同團」勾選(掃進來的這幾位互綁)。
  - 會員端:事後牌咖頁出現「今天和 OOO、XXX 同桌」,可一鍵互加。
- **後端觸發**:開桌寫 session 時,若標記同團 → 批次寫入 mahjong_buddies(relation='自帶團')。

### ② 整團升級「戰隊 / 姊妹團」(給關係一個身分)
- **機制**:常一起來的團 → 可命名成立「戰隊」(如「週二姊妹團」),給專屬身分。
- **給什麼**:
  - 團體優惠(揪滿一桌折檯費 / 戰隊專屬券)
  - 團體賽(戰隊對戰、戰隊排行榜)
  - 團體頭銜 / 戰隊徽章
- **心理機制**:從「一群朋友」變成「一個有名字的隊伍」→ 身分認同 → 更黏、更常來、更想壯大。
- **前端落點**:牌咖頁新增「我的戰隊」區(戰隊名、成員、戰績、揪團入口)。
- **後端**:新增 crews(戰隊)+ crew_members 表。優惠走 coupons(發給整隊),團體賽走賽事模組。
- **狀態**:⚠ 新概念,現有 schema 無 crews 表,需新增。

### ③ 裂變(網絡細胞分裂)
- **機制**:鼓勵團裡每個人「各自再揪自己的朋友」→ 一桌變兩桌、兩桌變四桌。
- **驅動**:
  - 推薦獎勵(揪到新會員,雙方得獎勵 → 對應 grant_rules 的 referral)
  - 裂變可視化(「妳的姊妹團已長到 12 人」「妳推薦的人又推薦了 3 人」)
- **意義**:指數成長的關鍵——不是 MIGI 一個個拉客,是客人幫你拉。一個核心會員可裂變出整個網。
- **前端落點**:小熊頁「收藏成就/推薦揪團」的推薦碼 + 裂變樹視覺;戰隊頁「邀朋友加入戰隊」。
- **後端**:referral 鏈紀錄(誰推薦誰,可追多層),對應 member_interactions / 推薦關係表。

### ④ 外部社群素材(脆 / IG 變免費行銷管道)
- **機制**:提供「可一鍵貼到脆 / IG」的揪團素材——美美的揪團卡、戰隊戰績圖,帶 MIGI 品牌 + 導流連結。
- **意義**:客人在自己社群揪人 = 免費曝光 + 品牌植入 + 導流回店。把客人的社群當免費通路。
- **前端落點**:揪團頁「生成揪團圖」按鈕 → 產一張帶 MIGI logo / 蜜桃粉風格的分享圖(可含「缺一咖、今晚七點、旗艦店」)→ 分享到脆 / IG。圖上連結導到 LIFF 入會 / 領券。
- **後端**:分享連結帶推薦碼 + UTM,點擊入會自動歸因(對應 online_claim 觸發發券)。
- **守紅線**:素材只談「揪人打牌、場地服務」,不出現賭博字眼。

## 二、配桌陌生人 →「媒合 + 促成 + 重逢」(護城河重點)

> 心法:這是 MIGI 無中生有創造關係的地方。三步把「陌生人同桌」變成「固定牌咖習慣」。

### a. 配得好(媒合品質)— 演算法核心
- **原則**:配桌不只「湊滿四人」,要「配合得來的人」。合拍才會想互加、想再見。
- **目標函數**:配桌演算法的目標不是「填滿桌」,是「**最大化未來互加機率**」。填桌是約束,互加是目標。
- **媒合維度**:
  - 段位接近(勢均力敵,打起來舒服)
  - 積分級距一致(想打一樣大的)
  - 牌型一致(台16 / 三人)
  - 時段可打到的時間重疊
  - 年齡 / 風格相近(軟性,可選)
  - 避開黑名單 / 迴避名單(硬約束)
  - 過去同桌合拍度(打過且願再同桌的優先)
  - 性別平衡機制(女性友善:女性場 / 混合場比例上限,女性設偏好)
- **前端落點**:會員端配桌頁(選牌型/積分級距/時間,已有);媒合結果通知。
- **後端**:配桌引擎(對應《配桌引擎技術設計》)。合拍度需牌譜資料中台支撐。
- **狀態**:⚠ 配桌引擎是 M2/M3 重點,合拍度演算法需資料累積後才精準。初期先用硬條件(段位/級距/時段),軟性合拍度後補。

### b. 臨門一腳(促成互加,降摩擦)— 時機是關鍵
- **機制**:收桌時系統主動推「今天同桌的小美打得不錯?加為牌咖,下次一鍵揪她」。
- **為何有效**:在「剛打完、印象最好」的當下促成 → 互加摩擦最低。隔天才推就涼了。
- **驅動**:互加獎勵(雙方各得養成值 / 點數)。
- **前端落點**:收桌結帳後,會員端跳「要不要把今天的牌咖加起來?」→ 顯示同桌三人 → 一鍵加(可全加 / 選擇加)。
- **後端**:收桌 settle 觸發(對應 M2 收桌的三項更新之外,加第四個觸發:推互加)→ 寫 mahjong_buddies(relation='配桌新識')+ 發互加獎勵。
- **狀態**:⚠ 需在 settle 流程加「促成互加」觸發 + 前端跳窗。

### c. 製造重逢(新關係變習慣 → 鎖客)— 最關鍵
- **機制**:互加後系統製造「重逢」:「妳的牌咖小美今晚有來,要不要一起?」
- **為何最關鍵**:一次同桌是緣分,**反覆重逢才是習慣**。重逢頻率決定鎖客深度。
- **驅動**:
  - 牌咖在線通知(牌咖到店 / 在線 → 推給你)
  - 一鍵揪(看到牌咖在線,一鍵發起同桌邀請)
  - 媒合優先同牌咖(配桌時優先把互為牌咖的人配在一起)
- **鎖客邏輯**:客人的牌咖越多、重逢越頻繁 → 離開成本越高(換別家 = 拋下整個牌咖網絡 + 段位歷史,重練)。**這就是「人鎖人」的護城河閉環。**
- **前端落點**:牌咖頁「現在在店裡 · 揪一咖」(已有原型)+ 牌咖到店主動推播(LINE)。
- **後端**:在線 / 到店狀態偵測 + 推播(對應 MA 自動旅程);配桌引擎加「同牌咖優先」權重。
- **狀態**:部分原型已有(牌咖頁在線揪咖),推播與配桌優先權重待 M3/M4 做。

## 三、完整閉環:一個陌生人怎麼變成被鎖住的常客

```
單獨來 / 差咖
  → ③系統配桌:配到合拍的人(媒合品質好)
  → 打完印象好
  → 收桌臨門一腳:一鍵互加(促成,降摩擦)
  → 成為牌咖(新關係建立,記在平台上)
  → 牌咖到店推播:「小美今晚有來」(製造重逢)
  → 反覆重逢 → 變固定習慣
  → 牌咖網越長 → 離開成本越高(人鎖人)
  → 護城河成形
```

對照外部揪團那條線:

```
自帶私局來
  → 報到綁定(收編關係資料)
  → 升級戰隊 / 姊妹團(給身分,更黏)
  → 各自再裂變揪友(網絡分裂)
  → 社群素材導流(免費行銷)
  → 整個關係網長在 MIGI 上
```

兩條線最終匯流:不管關係是「帶進來的」還是「MIGI 製造的」,都長在平台上、都靠重逢維繫、都越用越離不開。
