# MIGI 麻將連鎖 — 第一階段落地計畫 v0.1(從一家店開始)

> 原則一句話:**第一階段不是把酷東西做出來,而是證明「一個盒子會賺錢」。**
> AI 攝影機、電視牆、競技舞台、車隊、職業選手、IP 聯名 —— 第一階段全部不做。

---

## 0. 核心原則

先開一家乾淨、合法、好好營運的健康麻將店。只建「**法律上必須**、或**能用一家店便宜驗證假設**」的軟體;其餘全部人工頂著,邊做邊學真實營運規則,再決定後續自動化什麼。

最大的陷阱是:在還沒有一家會賺錢的店之前,就先把資料中台、AI 視覺、全自動配桌全做完。一家店規模下,很多事人工反而更好、更省,而且你會先學到真實的營運細節再去寫程式。

---

## 1. 第一階段要證明什麼

1. **法律 / 營運模型成立**:點數/計分卡、桌面不見現金、健康麻將定位站得住。
2. **單店單位經濟**:一家店能不能獲利?(佔用率、桌時、餐飲、會員、商品)
3. **差異化有沒有共鳴**:客人是否真的在乎「配桌品質」與「成績/段位」?(用人工先測)
4. **開始累積資料資產**:即使先靠手動輸入,也要開始長你的牌譜/成績資料。

---

## 2. 「建」vs「人工頂」的判準

只自動化符合以下任一條的:
- (a) 法律上必須 → **點數錢包/計分卡結算**
- (b) 一家店也無法人工處理 → **會員身分、點數結算**
- (c) 能便宜驗證關鍵假設 → **在 LINE 看到自己的段位/成績**

其餘一律:**人工 → 觀察 → 學會規則 → 第二階段再自動化**。

---

## 3. 要建的(最小系統)

| 項目 | 內容 | 備註 |
|---|---|---|
| LINE OA + LIFF | 會員綁定、儲值、查點數、查成績、送配桌請求 | 用你的 Supabase + LIFF 棧自建,省外包 |
| 點數 / 計分卡結算 | 儲值→計分卡→場地費結算,桌面不見現金 | **法律紅線,Day 1 必備** |
| POS + 桌台計時計費 | 開桌、計時、扣點 | 可現成 POS + 自建點數層 |
| 簡易後台 | 會員清單、段位、迴避旗標、手動輸入局結果 | 供店員配桌時看 |
| 資料表 | 依《配桌引擎》《資料中台》文件先建表 | 媒合先半人工,表先到位以利累積資料 |

---

## 4. 先用人工頂的(延後自動化)

- **配桌媒合**:店員看螢幕(會員清單 + 段位 + 迴避旗標)手動配。先學會真實規則,再寫全自動引擎。
- **成績擷取**:只手動/平板輸入「**局結果**」(誰胡、莊家、放槍者、點數),或直接抓全自動桌的數位分數。**完全不做逐張 AI 辨識**。會員仍能在 LINE 看到段位/和牌率。
- **安防**:一般 CCTV 存證(便宜、現成),不做 AI。
- **內容**:手機拍、經營社群;有機觀察出 1–2 個有魅力的常客/教練,先不簽約、不建攝影棚。
- **商品**:小量品牌麻將尺試水溫(低 MOQ),不做 IP 聯名大計。

---

## 5. 明確不做的(留給後續階段)

AI 逐筆牌譜辨識、大型電視牆 / 競技舞台 / 旗艦店、車隊、職業選手 roster、內容攝影棚、外部 IP 聯名、第二家店、資料湖 / OLAP。

---

## 6. 團隊(一家店)

- **你(Jim)**:策略、產品、**自建軟體**(Supabase + LIFF 是你的棧,等於省一個開發外包)。
- **店長 + 現場人員 3–5 名**:接客、配桌操作、結帳、餐飲;輪班覆蓋營業時段。
  - 接客 SOP 要從第一天就建立(這是連鎖未來複製的根)。
- **約聘 / 顧問(非全職)**:品牌與麻將尺設計、會計、法務(諮詢)。
- **拍攝 / 社群**:初期由你或店員兼。

---

## 7. 成本結構(數字請填在地報價)

> 不亂報精確金額;租金、裝潢、桌價各地差很大。以下是結構與相對量級。

**一次性資本支出(capex):**
- 押金、裝潢(健康麻將需明亮乾淨,不能像傳統賭間)— **主要**
- 全自動麻將桌(單價偏高,依桌數,是明顯一筆)— **主要**
- 桌椅、POS / 平板 / 網路、CCTV、招牌、首批商品 — 次要

**每月固定支出(opex):**
- 租金、人事薪資 — **兩大主導項**
- 水電網、餐飲/耗材進貨、行銷 — 中
- 軟體雲端(Supabase、LINE 推播)— **相對很小**

**省錢關鍵:** 軟體自建(你的棧)；桌數先抓夠用、別過度;旗艦級的東西全不做。

**抓損益的方法:**
```
營收上限 ≈ 桌數 × 每日營業時數 × 佔用率 × 每桌時單價  (+ 餐飲 + 會員 + 商品)
損益兩平佔用率 = 每月固定支出 / (桌數 × 月營業桌時 × 每桌時單價)
```
先算出「**損益兩平需要多少佔用率**」,這個數字會直接告訴你選點與桌數該怎麼定;若兩平佔用率高得不切實際,就要換點、降租或改桌數。

---

## 8. 粗略時程(階段,非固定週數)

1. **籌備期**:法務/商業登記、選點、裝潢、自建 LIFF/點數系統、採購桌具、招募與訓練、首批商品。
2. **試營運(soft launch)**:小規模開跑,半人工配桌、手動成績,密集觀察真實營運。
3. **迭代**:修配桌規則、看哪些資料真有價值、驗證單店損益。

---

## 9. 進入第二階段的條件

同時滿足才往下走(自動化 / 第二家店):
- 單店**穩定獲利**、佔用率達到健康水準。
- 客人**確實重視**成績/段位與配桌品質(有數據佐證)。
- 已累積**足夠的牌譜/成績資料**與營運 know-how。
- 有**現金流**支撐 AI 擷取或展店投資。

第二階段才接:AI 牌譜辨識管線(自動化成績)→ 全自動配桌引擎 → 第二家店(驗證「規則統一 + 成績可攜」的連鎖價值)。
