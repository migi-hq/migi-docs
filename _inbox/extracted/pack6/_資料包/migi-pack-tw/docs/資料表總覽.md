# 資料表總覽(M0 · 20 張)

> 這是什麼:`sql/applied/m0-schema.sql` 的可讀導覽。
> 什麼時候讀:要找某個資料放哪張表、或設計新功能要接哪張表時。

所有表共通:UUID 主鍵、審計欄(created_at/updated_at/created_by/updated_by)、軟刪除 `deleted_at`、`org_id` + RLS、org_id 不可竄改觸發器。

## 組織與人

| 表 | 用途 |
|---|---|
| orgs | 租戶(品牌/加盟主)。org_id = 租戶,store_id = 分店,一 org 多 store |
| stores | 分店 |
| staff | 員工 |
| members | 會員。含 `avatar_url`(檔案存 Storage,網址存這欄) |

## 錢包與計費

| 表 | 用途 |
|---|---|
| wallets | 會員錢包餘額 |
| wallet_txns | 錢包流水。**append-only,禁 UPDATE/DELETE**;餘額一律由流水推導,絕不直接設 |
| pricing_tiers | 計費規則(資料驅動,不寫死) |
| stake_levels | 積分級距(純娛樂麻將 → 300/100,可後台自建) |
| bonus_rules | 獎金規則 |

## 優惠券

| 表 | 用途 |
|---|---|
| coupons | 券種定義 |
| member_coupons | 會員持有的券(發放即一筆,用掉改 status) |

## 桌台與對局

| 表 | 用途 |
|---|---|
| tables | 桌台 |
| table_sessions | 開桌場次。含 `stake_level_id`、mode(matched 配桌 / private 包桌) |
| session_players | 場次參與者 |

## 商品與訂單

| 表 | 用途 |
|---|---|
| products | 商品(餐飲等) |
| orders / order_items | 訂單與明細 |

## 社交與媒合

| 表 | 用途 |
|---|---|
| member_availability | 會員可打時段 |
| mahjong_buddies | 牌咖關係(護城河核心) |
| member_interactions | 會員互動紀錄 |
